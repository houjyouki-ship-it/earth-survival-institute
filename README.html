地球存続研究所（Earth Survival Institute）設立計画

目的

地球上の生命・人類文明・人類が生んだ知性の絶滅を阻止し、可能な限り長期の存続確率を高めるための、検証可能な知見を蓄積する。

研究方針

  1. 脅威を時間軸（直近100年／1万年／10億年以上）で分類し、文献推定値と不確実性を明示する（threats/taxonomy.md）。
  2. 課題は「重要度 × 扱いやすさ（計算機で検証可能か）× 未解決度」で優先順位を付ける（priorities.md）。
  3. 各回で必ず1つ以上、再現可能な成果物（乱数シード固定のスクリプト＋出力＋図）を作る。
  4. 独自仮説は反証可能な形で書き、同じ回のうちに数値で検証し、棄却された結果も残す。
  5. 外部への操作は公開情報の閲覧のみ。実験は計算機シミュレーションのみ。

毎回の研究サイクル

  1. log.md・next_plan.md・open_problems.md・直近の research/*/report.md を読む。
  2. 前回スクリプトを再実行し、results.json が再現することを確認する。
  3. 文献を調べ、URLを実際に開けたものだけ引用する。
  4. 仮説 → シミュレーション → 批判的検証（感度分析・反例探索）。
  5. 成果物を保存し、open_problems / next_plan / log を更新する。

方法論規則（第2回追加）

  • 推定値の統計的意味を必ず書く（研究001 H1：同じ数値を「中央値」と読むか「平均」と読むかで、不確実性が長期生存確率を上げるか下げるかの符号まで反転した）。文献値を入力に使うときは、次のどれなのかを明記する：(a) 個人の点推定（例：Ord 2020）、(b) 回答者集団の中央値（例：XPT。報告書は質問ごとの中央値で、質問をまたいで同じ回答者とは限らない）、(c) 集団の平均、(d) 上限値（例：Snyder-Beattie 2019）。不明なら「不明」と書き、中央値・平均の両方で感度を出す。
  • 中央値は足し算できない：要因別の中央値の和は合計の中央値と一致しない（XPT超予測者：要因別絶滅中央値の和 ≈0.47% に対し合計中央値 1%【計算：taxonomy.md A'表より】）。合算はモデルを通して行う。
  • 事象の定義（絶滅＝人口5,000人未満／存続破局＝回復不能な崩壊を含む、など）を数値の横に書く。

記述ルール

  • すべての主張にラベルを付ける：【事実（出典）】 実在確認した文献に書かれていること／【推測】 筆者の判断・外挿／【独自仮説】 本研究所が提案し検証対象とする命題。
  • 数値は出典か results.json のどちらかに遡れること。捏造しない。
  • 「〜が重要だ」式の一般論のみの段落は書かない。
