研究054：南半球の第2拠点 S と束 T＋C の費用あたりの比較（open_problems 103＋100）

問い

批判的検討

  • 8つの仮説がすべて支持されたのは、費用の差（約14倍）が価値の差（0.5〜1.7倍）より大きいためで、結論は S の費用の構造（建設に加えて 20〜100年の維持費、どちらも資本費と同じ桁）で決まる。届く確率は 0〜1 のどこに置いても順位を変えず、事前登録の閾値は差に比べて緩かった。
  • 反例の探索：S_full が束を費用あたりで上回る組み合わせは、維持費なし・XPT の重み・軽い崩壊だけ、の3つを重ねたときに確率 0.1〜0.2 で現れる（維持費なしの A_XPT_S で P=0.18、軽い崩壊だけで 0.076）。S_full が束と並ぶには、金庫の物差しの外に価値の 11倍（A_XPT_S）〜27倍（A_Ord）の追加（重い崩壊だけなら 86〜154倍）が要る。
  • 価値の単位が高層の星重みしか数えない。S_full の全写しは低層や AWA の他の預託物も運ぶが、模型では数えない。S_TC が S_full の価値の 84% を持つのはこの単位のせいでもある。c_TC=0.3（一般の回復と T3 の社会にとって束の写しは全写しの 3割の価値）にしても S_TC の CE は 6.7〜13 で、結論は変わらない。
  • H66e は TAB の費用の置き方に乗る。CE は TAB の費用で割った比なので、T を 024 の g_req（0.7〜9 MB）で書けば TAB が安くなり、S_TC の CE は 0.91（A_Ord）に下がる。このとき S_TC の費用（中央値 $63万）は束（$69万）と同じ程度で、比べる意味は「束の費用と同じ額で南半球に写しを置く」ことになる。S_TC の費用（手続き・預け先の年額）はほぼ全部が推測で、公開の価格は北半球の AWA の預託（€8,900 から）しかない。
  • NUC_G と u_frag：A_XPT_S で S の価値の 81% は NUC_G から来て、その大半は豪州の脆い T3 の社会が窓内に南の拠点を読む場合（u_frag=1）である。u_frag を u（中央値 0.16）にすると S/T＋C は 0.090→0.035 に下がる。034 と同じく、脆い T3 の社会が手元の写しをどれだけ持つかが S の価値の最大の未知で、費用ではなく価値の側の問題。
  • 重い崩壊での届く確率は時間に依存するはずだが入れていない。重い崩壊では T2 まで数百年かかり、その間に拠点の場所の知識が残るかは主の金庫にも S にも効く【推測】。模型では発見の確率を崩壊の時点の値として置いている。
  • 040 の物差しは 051・052 の改訂（A_Ord 0.00461）の前の値で、033 にある回収マイコンの読者の経路を含まない。T＋C の比 2.56 が 033 の値（2.6〜2.8）と合うので、束の側の誤差は小さいとみる【推測】。
  • 為替（EUR、NOK、AUD）は出典の対の値か推測の幅で置いた。施設のアンカーを1つずつに固定しても、CE の比の中央値は A_Ord で 0.027〜0.047、A_XPT_S で 0.064〜0.114 の範囲を動くだけだった。

結論

南半球に専用の拠点を新しく建てる S_full は、建設（$1,300万〜4,200万、種子庫の改修で建設費の4倍が後からかかった例を含む）と 20〜100年の維持で中央値 $6,800万かかり、板の手引きと小窓版の束（中央値 $490万、ほぼ執筆の費用）の約14倍である。価値は XPT の重みでは束より大きいが（1.2〜1.7倍）、費用あたりでは束の 1/27〜1/11（重い崩壊だけなら 1/86〜1/154）で、届く確率を 1 にしても並ばない。S の価値の 89〜99% は軽い崩壊から来る。一方、束を作った後に南半球の既存の施設に束の写しだけを預ける S_TC は、S_full の価値の約 85% を約 1/100 の費用で得て、費用あたりで板の手引きの 11〜25倍（重い崩壊だけでも 4〜6倍）になる。順番は「束 T＋C → 南半球への束の写し S_TC」で、専用の第2拠点は金庫の物差しでは正当化できない。

この結果を受けて、誰が何を変えるべきか

  • GitHub Archive Program・Piql など金庫の運営者：南半球に新しい専用の拠点を建てる前に、板の手引きと小窓版の束（約4〜10リール＋板）を作り、その写しを南半球の既存の施設（豪州・NZ の国立図書館や大学、Tasmania の Earth's Black Box のような計画、MOM 型の板の預かり）に預ける。予算の目安は束で数百万ドル、南の写しで数十万ドルで、全写しのための専用拠点（数千万ドル）より先にする。
  • 本研究所：032〜034 の「南半球の第2拠点」の提言を「南半球への束の写し」に置き換える。103 を閉じ、残る未知を S_TC の実際の預け先と費用（147）、時間とともに拠点の場所が忘れられる効果（149）、脆い T3 の社会にとっての金庫の価値 u_frag（150）に移す。

既存研究に対する新規性

Ord と XPT は崩壊後に何を残すべきかを費用で比べない。種子庫・AWA・MOM・Long Now は自分の施設の費用や価格を個別に公開するが、互いを同じ価値の物差しで比べていない。本研究は、公開の建設費・改修費・運営費・預託価格を、同じ崩壊の模型（040）の価値に入れ、「新しい拠点」「束」「既存の施設への束の写し」の費用あたりの比を、重い崩壊と軽い崩壊に分けて出し、届く確率を 1 にしても専用の拠点が束に並ばないことを示した。確認した資料には、この比較は見当たらない。
