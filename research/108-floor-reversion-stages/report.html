問い

038〜107 の段の模型は、生き残りの群の人数 n が段の閾値 N_k（N_Fe・N_lens・N_T2e）を下回ると段を即座に失う二値。059 で伝達の損失は一定でなく床からの差に比例（a≈0.37〜0.39／世代）と分かった。技能を連続にし、群が育って閾値に戻るまでに技能が要求を割るかで段の喪失を決め直すと、重い崩壊（st 4〜6）の割合・T0 再出発・F_heavy はどれだけ動くか。

模型（【独自仮説】の形）

  • dz/dt = κ(ln N(t) − z)。z は技能を ln N の単位で測る（Henrich の釣り合い z*=ln N の形、段の要求 z_k = ln N_k）。N(t) = n·e^{rt}（r は 038 の r_pop）、z(0) = ln N_pre（主は世界人口 8.232e9）。
  • 解析解：z の最小値 z_min = ln n + (r/κ)·ln(κA/r)、A = ln N_pre − ln n + r/κ（κA/r ≤ 1 なら減らない）。z_min ≥ ln N_k なら段 k を保つ。実効の閾値の倍率は exp(−(r/κ)ln(κA/r))。
  • κ→∞ で 038 の二値の割り当てに一致（F_heavy の差 0、T2 の差 0 を assert）。動かしたのは 038 の割り当てと一致する重い崩壊の標本だけで、該当の全標本（BIO・CASC・AS・U3）が一致した。

資料（本回取得、sources/ に保存）

  • 【事実（Wikipedia: Aboriginal Tasmanians）】約 6000 BCE の海面上昇で本土から切り離され約 8,000 年孤立（Cosgrove 1995）。同じ頁の別の節は水没を 14,000〜12,000 BCE とする（Hamacher 2023）。約 4,000 年前に魚を食べなくなり骨角器から石器へ移った。その意味は「強く争われ」、草地の拡大による経済の変化とする説もある（Manne 2003）。接触前の人口の推計は 3,000〜15,000（Madley 2008）。
  • 【事実（Wikipedia: Generation）】世代は「generally considered to be about 20–30 years」。
  • 【事実（059 の sources、Muthukrishna 2014 実験2）】床への戻りの率 a = 0.39（1手本）、0.37（5手本）／世代。

κ の置き方

  • κ_lab = a/Tg、a ~ U(0.37, 0.39)、Tg ~ U(20, 30)：中央値 0.0152／年（5〜95% 0.0129〜0.0185）。【推測】実験室の数分の「世代」を人の世代に読み替えている。
  • κ_hist：人口一定の群で z(t) = ln n + (z0 − ln n)e^{−κt}、喪失は z = ln N_k → κ = ln R / T_loss。T_loss = 孤立 8,000 − 喪失 4,000 ≈ 3,500〜4,500 年、R = (z0−ln n)/(ln N_k−ln n) は資料がなく U(ln 1.1, ln 10)【推測】。中央値 0.00030／年（a_hist は 1 世代あたり 0.0074、5〜95% 0.0013〜0.0145）。別の版は T_loss 10,000〜12,000 年。

批判的検討

  1. κ_hist は 1 件の島の、原因の争われている変化から出した。骨角器の消失が経済の選択なら、技能の喪失の速さの証拠にならない【推測】。R も資料がない。
  2. 技能だけが残っても、製鉄・ガラス・工作機械の段は炉・燃料・道具などの資本と分業の網に依存する。z は技能しか表さず、κ_hist の版は資本の喪失を無視した上限の側【推測】。
  3. 実験室の a は数分の課題の 10 世代で、産業の技能の世代あたりの落ち方を測っていない。κ_lab も外挿。
  4. 全段で同じ κ、要求を ln N_k に揃える形は 058・059 の Henrich の形の延長で、段ごとに違う κ は扱っていない。
  5. 以上から、本回の結論は「二値の模型を使い続けてよいかは κ が 0.002〜0.006／年の分かれ目のどちら側かで決まり、手持ちの 2 つの根拠はどちらも弱く逆側にある」に留まる。
