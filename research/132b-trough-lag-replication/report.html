研究132b（132 と同時の別実行・独立の再現）：停滞 stag と phi を「谷からの遅れ」で揃えた F_heavy（open_problems 307）

注：F_heavy・V は生存確率や復興確率ではない（模型の中の価値の比）。事前登録 PREREGISTRATION.md（2026-10-26 05:48 JST、sim.py と新しい資料の前）。結論は模型の中での順位で、外部の検証はまだ。

何をしたか

125 の停滞の年数（始まりから数えた超過）が「谷からの遅れ lag ＋ 下り坂 200 年」に分かれることを確かめ（Greece 262.5＝62.5＋200、Britain 407.6＝207.6＋200、sim.py で assert）、lost 側の stag と kept 側の phi を同じ「谷からの遅れ」で作り直した。127 の仕組み（遅い κ、W、H1000、p|lost 0.9、p|kept 1/6、事例の抽選の添字は 127 と同じ）で 6 版を回した（sim.py 約 334 秒）。VA0 は 131 の phi=0 の F_heavy と D2rz・D1・D4 で差 0（assert）。あわせて 400 年前後のイタリアの人口の公開の推定を探した（sources/、SHA256SUMS）。

批判

  1. どちらの定義が模型に正しいかは決着していない。模型の人口は崩壊の直後に谷の大きさで始まり下り坂を持たないので、lost 側は始まりから数えた A（下り坂を含む）が模型の待ち時間に合う。B は下り坂 200 年を落とすので lost の待ちを短く見積もる側【推測】。一方、phi を A で測るには kept 側に共通の始点の人口が要り、それが見つからない。VAB（lost は A、免れた側は谷からの遅れの比）は両者の折衷で 2.16〜1.97。
  2. 下り坂の 200 年は Greece・Britain とも 125 の推測の谷の年（Britain の 600、Greece の 前1000）から来ており、2 件とも丸めた値。
  3. phi_Italy は谷の高さ（400 万か 600 万か）で 0.8〜1.5 と動き、131 の「定義で決まる」問題はイタリアについて残る。France・Iberia の phi 0 は移入（Frank・Visigoth、711 以後）を含む。
  4. Greenland の 650 は消滅の下限で、定義に関係なく同じ値を使った。

誰が何を変えるべきか（模型の中での順位、外部の検証はまだ）

模型の維持者は遅い κ の重い崩壊の D2rz の F_heavy を、定義を揃えた範囲として「1.73〜1.90（谷からの遅れ）〜1.97〜2.16（lost は始まりから、免れた側は谷の比）」で示し、131 の 1.27〜1.43 は始点が揃っていない比較なので感度の表から外す。主の一点が要るなら、模型が下り坂を持たないことを根拠に VAB_mean の 2.16 を置き、下端を VB_it の 1.73 とする。D2rz の推しはどの版でも不変。
