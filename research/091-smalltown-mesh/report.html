研究091：写しを小さな町にも置ける網目（open_problems 223）

注：TC/V0 は生存確率・復興確率ではない。提言は模型の中での順位（外部の検証はまだ）。

問い

090 で農村の生き残りを入れると写しに届かない群が 0.69→0.75 に増えたが、写しの候補は 074 の Natural Earth（NE）の大きな点だけだった。GeoNames cities1000 の点を写しの候補にして 074 と同じ貪欲な網目を作り直すと、同じ 35・200 部で重い崩壊の TC/V0 はどれだけ上がるか。

方法

  • 090 の sim.py を版の走査の前まで exec（087・075・084 の差0の assert と PT_s の assert を含む）。090 の mesh35_M・mesh200_M・mesh35_R を差0で再現（assert、差 0.0）。074 の貪欲な網目を関数に書き直し、074 の入力で最初の 200 か所を完全に再現（assert）。
  • 新しい網目：生き残りの点（090 の版の重み）を 0.5° のます目 22,685 個に集め、候補はます目ごとの GeoNames の人口最大の点（GN）または 074 の NE の点 6,891 個（NE）。目的は 074 と同じ q=0 の届く確率の被覆 A。
  • 網目：GN_M（主：候補 GN・重み M）、GN_B（重み B_GN）、GN_Rall（重み R_all）、NE_M（候補 NE・重み M）、基準 NE074。
  • 評価：090 の 5 版（B_GN・R・R_all・M・M2）の群の点で 075 の器の重い崩壊 TC/V0（A_Ord/U3）。新しい乱数なし。入力はすべて既知なので仮説はすべて「入力判明後の予測」。新しい資料の取得なし。

  • 【推測】作りと評価の重みが違う組でも上げは残る（GN_B を M で評価 +0.0056、GN_M を B_GN で評価 +0.0021）。作りと評価を同じ重みにする楽観は 35 部の M で 0.0015 程度（GN_M 0.6739 対 GN_B 0.6724）。

仮説の判定（すべて予測）

  • H103a 支持（+0.0071 ≥ 0.005）。
  • H103b 支持（B_GN で 0.6781 ≥ 0.6760）。
  • H103c 支持（届かない群 −0.065 ≥ 0.02）。
  • H103d 棄却（NE_M の上げ +0.0068 は GN_M +0.0071 の半分未満ではない。効くのは候補の集合ではなく作りの重み）。
  • H103e 棄却（35→200 は +0.0423 < +0.0465）。
  • H103f（記述、数えない）：中央値 50,000 未満ではなく 1,196,214。

批判的検討

  • 貪欲な網目の目的（q=0 の A）と評価（TC）は別物で、NE_M は A では GN_M より低い（200 部 0.583 対 0.586）のに 35 部の TC はほぼ同じ。目的関数を TC に寄せた作り方は試していない（新規 224）。
  • 候補の点は「ます目の人口最大の地名」で、そこに冊子を受け入れる館があるかは見ていない。200 部の GN_M には人口 1 の地名が入っており、実在の受け入れ先の制約（078〜080 の受け入れ率）を入れると小さな町の候補はさらに効かない向き（新規 225）。
  • ます目 0.5° に集めた重みは 075 の群の点と同じではない（作りの段だけの近似、評価は元の点）。
  • 【独自仮説】重い崩壊の TC での網目の改善は約 +0.007 で頭打ちで、写しの置き方の最適化の線は収穫逓減に入った。残る大きな幅は生き残りの居場所の模型（農村の配り方、195・218 の残り）の側にある。

誰が何を変えるべきか（模型の中での順位、外部の検証はまだ）

冊子を配る運営者は、35 か所の網目を農村の生き残りを含む重みで引き直す（得は約 +0.007）。ただし置き先を村や小さな町に広げる必要はなく、中規模以上の町の館のままでよい。本研究所は重い崩壊 mesh35 の主を 0.667 から 0.674 に改め、網目の作り方の線はこの回で閉じる方向で扱う。
