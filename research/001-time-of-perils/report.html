研究001：「危険の時代」ハザードモデルによる長期存続確率と介入効果

再現：cd research/001-time-of-perils && python3 sim.py（seed=20261014, N=200,000, 要 numpy/matplotlib）→ results.json, fig_survival.png, fig_posterior_tail.png

1. 背景

  • 【事実（Ord 2020, 第1章 PDF）】今世紀の存続リスクは約1/6、20世紀は約1/100。このリスク水準は何世紀も続けられず、「危険の時代」は少数世紀で終わるか破局するかのどちらかと主張。
  • 【事実（Snyder-Beattie et al. 2019）】自然要因による絶滅の年率は 1/87,000 未満（相対尤度0.1基準）。人為リスクには適用できない。
  • 【推測】Ordの「危険の時代」論は定性的で、(a) リスク強度を下げる介入と (b) 危険の時代を早く終わらせる介入の比較、(c) 推定値の不確実性の影響、を同一モデルで定量化した資料は今回の調査範囲では見つけていない（網羅的調査ではない）。

2. モデル

年率ハザード h(t) = h0·exp(−t/τ) + h_nat、生存確率 S(T) = E[exp(−∫h)]。 - h0 中央値 = 1−(5/6)^(1/100) = 0.00182/年（Ordの1/6を年率換算） - τ 中央値 = 200年【推測：Ordの「少数世紀」を指数減衰に置換】 - h_nat = 1/87,000/年（Snyder-Beattieの上限を保守的に固定値として使用） - 不確実性：h0, τ を対数正規（σ=1.0, 独立）【推測】

4. 独自仮説と検証

H1【独自仮説】推定の不確実性を考慮すると、点推定より長期生存確率は高くなる（ジェンセンの不等式、exp(−x)が凸）。 - 検証：専門家の数値を「中央値」と解釈するとσ↑で S(1万年) は 0.619→0.545(σ=1)→0.503(σ=2) と低下。「平均」と解釈すると 0.619→0.702(σ=1)→0.823(σ=2) と上昇。 - 判定：条件付きで棄却。結論は推定値の統計的意味（中央値か平均か）に完全に依存し、符号すら反転する。→ 文献推定値を合算するときにはこの区別を明記する必要がある（新しい方法論的規則としてREADMEに追加候補）。

H2【独自仮説】長期生存を決めるのは累積危険量 h0·τ だけであり、「強度半減」と「期間半減」は長期的に等価だが、直近では強度削減が優る。 - 検証：T≥1万年で A と B は一致（0.659 vs 0.659、10万年では小数6桁まで一致）。T=100年では A=0.903 > B=0.854。T≫τ で累積ハザード→h0·τ となる解析結果と整合。 - 判定：支持（ただしモデル構造による自明な部分を含む。非自明なのは「同じ費用で強度と期間のどちらを削れるか」という費用関数で、未解決）。

H3【独自仮説】自然ハザードを上限値で置くと、10万年以降の生存は人為リスクではなく自然床が支配する。 - 検証：C（自然床=0）は10万年で0.611、ベースライン0.194。100万年では A/B 介入の効果はほぼ消え（7.5e-6）、自然床のみが効く。 - 判定：支持、ただし強い留保。1/87,000 は上限であり真の値は桁違いに小さい可能性がある【事実（同論文：Homo属基準で <1/870,000）】。その場合 h_nat=1/870,000 では10万年生存の床は e^(-0.115)≈0.89 となる【計算】。

補足：1万年生存で重み付けすると、h0·τ 下位25%のパラメータ領域が生存質量の38.1%を占める（事前では25%）。生存世界は「楽観パラメータ世界」に偏るが、極端には集中しない。

5. 批判的検証（限界）

  • 指数減衰は仮定。危険が下がらない（τ→∞）シナリオや、技術進歩で新リスクが出る増加型を含んでいない。
  • h0 と τ を独立としたが、【推測】リスクが高い世界ほど危険の時代も長い（正相関）可能性があり、その場合不確実性の影響は大きくなる。
  • 「存続破局」に回復不能な崩壊を含むOrdの定義と、絶滅のみのSnyder-Beattieを混ぜている。
  • Ordの推定は個人の主観。XPTでは専門家と超予測者が大きく不一致【事実（forecastingresearch.org/xpt）】。

6. 結論

  1. 【計算結果】Ord推定を年率化し危険の時代τ=200年と置くと、1万年生存確率は 0.54〜0.66（不確実性の解釈・介入により変動）。
  2. 【独自仮説・支持】長期的には「強度」と「期間」の削減は等価、100年スケールでは強度削減が4.9ポイント優位。
  3. 【独自仮説・条件付き棄却】不確実性が存続確率を上げるか下げるかは、推定値が中央値か平均かで反転する。
  4. 【推測】10万年超の存続には自然リスクの床（=地球単一拠点への依存）の低減が必要になる可能性があるが、床の真値に強く依存する。
