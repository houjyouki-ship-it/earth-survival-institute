批判的検討

  • 結論は「分散した clone がどれだけ残るか」（f_orph）でほぼ決まる。拠点の網羅と生存だけで u を見積もると（clone なし）、XPT の2組では S が束より上になる（確率 0.9995 以上）。主設定で S が下になったのは、f_orph を 0.003〜0.3 と置いたからで、これは本研究所の推測であり資料の裏付けがない。交差点の f_orph は A_XPT_S で 0.37、A_XPT_E で 0.087 なので、A_XPT_E では主設定の範囲の中で順位が入れ替わる。
  • 拠点の地理は事実として効く。確認した完全な写しはすべて北半球（欧州・北米・エジプト）にある。そのため全面核戦争（NUC_G）の u は BIO の約8倍になった。ただし地域の生存確率は推測で、8倍という値そのものはこの推測から来る。
  • H46f の棄却は境界（18.8% と 20%）。脆い T3 の計算機経路にも u を当てると S はさらに約2割下がる。主設定は 033 と比べやすいように u_frag=1 にしたが、一貫させるなら u_frag=u のほうが自然【推測】。
  • u は内容の「量」しか見ていない。T3 社会が手元の写しを持っていても、使える形で探し出せるかは別の問題【推測】。逆に、T3 社会の多くは金庫の中身より新しい版を持っているので、u はさらに小さいかもしれない。
  • 交差点の比較は、Shapley の和、片方だけの値、束の上の限界値の3通りで答えが違う。どれが政策の問いに合うかは、予算が「どちらか一方」か「順番に両方」かで決まる。費用を入れた比較（103）が必要。

結論

金庫が計算機の社会に足す価値 u を資料の拠点配置から見積もると、分散した clone が残る限り u は 0.0005〜0.016 と小さく、033 の第2拠点 S の値は 1.9〜4.9 倍の水増しだった。置き直すと S の重み付き Shapley は 0.032〜0.050 で、板の手引きと小窓版の束（0.034〜0.070）を下回る（P(S＞束) は 0〜0.28）。ただし、この順位は「clone で補えない割合」が 9〜37% を超えると逆転し（XPT の重み）、clone を数えなければ S が上になる。確認した完全な写しがすべて北半球にあるため、全面核戦争では金庫の価値が他のシナリオより大きい。

この結果を受けて、誰が何を変えるべきか

  • Software Heritage と GitHub Archive Program の運営者：完全な写しや 17,000件の写しの次の置き場所を、南半球（例：オーストラリア・ニュージーランドの大学や国立図書館）から選ぶ。確認した公開資料の範囲では南半球に完全な写しがなく、全面核戦争で金庫の価値が他より大きくなる原因がこれである。
  • 本研究所：今後、第2拠点 S の価値は T3 保持の結果を u（主設定 0.0005〜0.016）で割り引いて報告する。032・033 の「S が最大」は撤回し、「束が上、ただし clone の残り方しだい」と読み替える。

既存研究に対する新規性

Ord と XPT は崩壊後の技術段階も、どの写しが残るかも扱わない。GitHub Archive Program と Software Heritage は写しを増やす理由を述べるが、写しの地理的な偏りが崩壊の種類ごとに価値をどう変えるかは定量化していない。本研究は、公開されている写しの場所から崩壊シナリオごとに金庫の追加価値を見積もり、第2拠点と知識保存の束の順位が分散した clone の残り方で決まり、その分岐点が 9〜37% であることを示した。この組み合わせは、確認した資料（Ord、XPT、Xia 2022、GitHub GUIDE、Software Heritage、Internet Archive の資料）には見当たらない。
