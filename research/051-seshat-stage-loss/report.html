研究051：体系的な標本（Seshat Equinox-2020）で数え直した崩壊の後の段の喪失 h（open_problems 137）

注（2026-10-21、外部査読への対応で追記）：本報告の価値・V/V0・TC（V0 比）・A などの指標は模型の中の量で、生存確率でも文明の復興確率でもない。「誰が何を変えるべきか」などの提言は模型の中での順位で、外部の検証はまだ。

問い

048 の h（未知の人為リスクのうち T0 から再出発する割合）の4つの読みは、一人が選んで符号化した有名な崩壊18件から出した（V1 0.222、V2 0.195、V3 0.082、V4 0.028）。地域と複雑さで体系的に選ばれた標本（Seshat の35 NGA、世紀ごとの時系列）で、崩壊を機械的な規則で拾い、その後の段の喪失を数えると、h は 048 とどう違い、P1 の分かれ目 h*=0.097 のどちら側に来るか。

批判的検討

  • 048 の高い読みの多くは例の選び方から来ていた【推測】。有名な崩壊18件では V1 が 0.22 だったが、体系的な標本の政体の崩壊73件では文字を失ったのは2件で、その2件はどちらも 048 の Mycenae と Indus に当たる例だった（Crete は Mycenae と同じ青銅器時代末のエーゲ海の崩壊）。体系的な分母には、征服や分裂で政体が小さくなっても技術が残った例が多く入る。
  • ただし分母が広すぎる可能性もある。人口の半減には征服による入れ替えが含まれ、地球規模の崩壊の類例としては浅い。深い崩壊（SPC −1.0）に絞ると S1・S2 は h* をわずかに超える。SPC は文字などの情報の変数を成分に含むので、この版は文字の喪失と一部循環している。「どの崩壊が類例か」はデータでは決まらず、h が h* のどちらにあるかは今もこの選択に乗る。
  • S2 の4件のうち2件（Susiana の Sasan 朝の後、Upper Egypt の東ローマの後）はアラブの征服の時期で、技術の喪失というより符号の付け方の変化かもしれない。これを外すと S2 はさらに下がる。S4 の唯一の例（Cuzco）も符号の空白の疑いがある。体系的なデータは喪失を多めに数える側に誤る可能性があり、主の版の値はむしろ上限に近い。
  • 背景率は小さく、信号は本物。喪失は崩壊の窓に 3〜7倍集まる。符号の揺れで作られた数字ではない。
  • Seshat の標本は孤立した島（049・050）をほぼ含まず、V3 は作れなかった。050 で孤立は大きな生き残りの h を上げないと分かっているので、致命的ではない。
  • 価値はほとんど動かない。読み・分母・規則の10版すべてで A_Ord は 0.0042〜0.0060 に収まる。変わるのは「重い崩壊が価値の過半か」という判断で、主の版では 0.44〜0.50 と過半に届かない。

結論

体系的な標本で数え直すと、崩壊の後に文字を失った割合は 4%、2つ以上の技術を失った割合は 7%、金属をすべて失った割合は 2% で、048 の有名な例の集合の 1/5〜1/3 だった。主の版ではどの読みも h*（0.097）を下回り（文字か役人の S1b だけが境界の 0.095）、重い崩壊から来る価値の割合は 0.44〜0.50 になる。深い崩壊だけを分母にすると h* をわずかに超えるので完全には決まらないが、048 の「V1・V2 なら h>h*」という根拠は弱まった。重み付きの A_Ord は 0.0046（U3 の 0.60倍）で、版によらず 0.0042〜0.0060 に収まる。

この結果を受けて、誰が何を変えるべきか

  • 本研究所：A_Ord の主の値を 048 の V2（0.00545）から Seshat の S2（0.00461）に改め、「重い崩壊が価値の過半」とは書かず「重い崩壊と軽い崩壊が約半分ずつ」と書く。固定の最優先指示は残すが、その根拠（h>h*）は主の版で支持されなかったと明記し、優先を続けるかの判断をユーザーに返す。
  • 金庫・手引きの作り手：重い崩壊と軽い崩壊の寄与がほぼ同じなので、重い崩壊向けの特徴（肉眼で読める板、T0 からの手引き）のために、軽い崩壊での読み取りやすさ（機械で読む媒体の容量と規格）を犠牲にしない設計を選ぶ価値がある。

既存研究に対する新規性

Zenodo の記録は Equinox-2020 を今後の一連の出版の基礎のデータと説明している。確認した資料の範囲では、「崩壊の後に技術の段を失った割合」を機械的な規則で数え、地球規模の崩壊の再出発の深さの事前分布にして、知識の金庫の価値の分かれ目と突き合わせた例は見当たらない。048 の手作業の参照の集合の選び方の偏りを、同じ問いの体系的な標本で量った点も新しい。
