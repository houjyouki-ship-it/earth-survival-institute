研究077：座標の冊子1部ごとの費用 per_P を公開の価格で置き直す（open_problems 198）

注：TC/V0 と費用あたりは模型の中の価値の比で、生存確率でも復興確率でもない。提言は模型の中での順位（外部の検証はまだ）。

問い

076 で、写しを 35→200 部に増やす限界の費用あたりは 061 の per_P（印刷 logU($100,$1,000)＋送付 U($25,$50)、根拠は粗い【推測】）では平均の 0.14倍だが、per_P を 1/10 にすると重い崩壊では限界が平均を上回り判断が逆になった。印刷の公開の価格で per_P を置き直す。事前登録は PREREGISTRATION.md（2026-10-21T04:35Z、資料を開く前）。

資料（本回開いて確認、sources/ に保存し SHA256SUMS.txt）

約100頁・白黒の本1部の印刷費： - 【事実（Amazon KDP の印刷費）】白黒 24〜110頁は Amazon.com で 1冊 2.30 USD（大判 2.84）。 - 【事実（The Book Patch）】1〜49部 $2.75、100〜249部 $2.34。 - 【事実（BookPrintOnDemand.com）】$1.40/表紙＋$0.011/頁、1部の最低 $2.50。 - 【事実（Spines）】acid-free, archival-grade の紙をうたい、POD は 200頁の白黒で $2.90 から。 - 【事実（BookBaby）】POD の paperback は $5〜$8、acid-free, uncoated の紙を選べる。 参照（記述）：マイクロフィルムの複製1巻 $58.75〜$90（【事実（Indiana SIML の申込書 $59・$72、Kansas Historical Society $60・$75、BGSU $90、UW Libraries $58.75）】）。金属板は公開の製造価格がなく、Rosetta Archive Pendant は $1,000 以上の寄付への返礼で製造の価格ではない。NanoRosetta は価格を載せていない。 注意：acid-free は業者の自己申告で ISO 9706 などの認証の確認ではない。少部数の POD の価格で、耐久の製本（布装・糸綴じ）は含まない。

方法

076 の sim.py を「順位」の節の前まで exec し、076 の CE 全値と重い崩壊の TC を差0で再現（相対差 0.0）、費用の式を per_P の関数として書き直して 076 の Cost と一致を確認、per_P×0.1 の版で 076 の値（59.79）も再現した。新しい per_P＝印刷 logU($2.30, $8.00)＋送付 U($25,$50)（送付は 061 のまま、seed 20261077）。版（記述）：印刷×3（硬い表紙の代わり）、送付なし、送付×2、マイクロフィルム1巻。TC は変えず費用だけ置き換えた。

仮説の判定（分類つき、閾値は登録どおり）

  • H89a（確認的）：印刷1部の中央値 < $100 → 支持（$2.75）。
  • H89b（確認的）：acid-free の価格は普通の 3倍未満 → 支持（1.88倍。ただし各2件・3件の小標本）。
  • H89c（予測）：主・全体・α=0.5 で限界/平均 < 1 → 支持（0.37）。
  • H89d（予測）：主・重い崩壊・α=0.5 で限界/平均 > 1 → 支持（1.0008）。ただし境界の上ぎりぎりで、印刷×3 や送付×2 では逆になる。実質は「ほぼ等しい」と読むべき。

批判的な検討

  • 061 の印刷の範囲は公開の価格の約 40〜400倍高かった。古い結論「35部で十分、増やすのは平均の 1/7 の効率」は弱まり、重い崩壊を重く見る人には 200部が 35部と同等以上の効率になる。
  • 結論を決める未知は印刷から 送付・受け入れの1部ごとの費用（根拠なしの U($25,$50)）に移った。送付なしでは全体でも限界が平均の 3〜5倍、送付×2 では重い崩壊でも α=0.5 で 0.58。
  • 固定費（prep_P と primer の準備、中央値 約 $1.7万）は変えていない。35部で1部分の費用は約 $2千で、総費用の大半は固定費。これも根拠は粗い【推測】。
  • POD の紙が百年単位で残るかは価格からは分からない。写しの寿命 τp（062 の中央値 522年は歴史の印刷本）と POD の紙の寿命の差は未検証。

誰が何を変えるべきか（模型の中での順位、外部の検証はまだ）

冊子を配る運営者は、印刷費（約 $3/部）ではなく、図書館への送付と受け入れの手間で部数を決めることになる。受け入れの費用が1部 $25 程度以下なら 35部で止めず 200部まで配る案を検討し、重い崩壊を重く見るほどその判断は強まる。本研究所は 061〜076 の per_P を公開の印刷費に改め、次は1部ごとの送付・受け入れ費と図書館の受け入れの可否（open_problems 200）へ。
