問い（open_problems 136＋138）

048 で交易が断たれた生存例（Mycenae、Easter Island）の最上位の段の喪失は 0.75、交易が続いた10件は 0.20（2件、p=0.11）。孤立した島や植民地を事前に決めた規則で足して、(1) 孤立した生き残りで技術の喪失はどれだけ起きるか、(2) それは集団の大きさで説明されるか、孤立そのものか、(3) 逆の因果（崩れたから孤立した）は分けられるか、を調べる。孤立の効きを集団の大きさの関数として 047 の P1 の模型の生き残りの大きさ（U3・CASC・BIO の nmax）に写し、h を置き直して h*（P1 で 0.097）と比べる。138：h* を閾値の版（E2、P1、P2、P3、固定 M=3・10・30、048 の歴史の χ）ごとに出し、重い崩壊を優先する判断が閾値の線と h の線のどちらに乗るかを分ける。

符号（本回取得した本文の引用に基づく。判断は【推測】）

解析

  • A：孤立した生き残りの L の点の平均（0.5 は半分）と Jeffreys の Beta 事後（0.5 は Bernoulli(0.5) で振る、seed 20261049、2万回）。048 の χ=0 の2件のうち Easter Island は重複なので1回だけ数え、Mycenae は文字のある社会として別に足した版も出す。
  • B：ロジスティック回帰 logit P(L=1) = a + b·(log10 N − 4)。a, b に N(0, 2.5²) の事前、格子で事後。N と 0.5 の符号を標本ごとに引き直して事後を混ぜる。P(b<0)、N=1e3・1e4・1e5・1e6 の予測。感度：log10 T_iso を足す、env=1 を 0 にする、Andaman を 0.5 にする。
  • C：孤立した集落のうち ended の割合と、生き残りのうち L の割合を比べる。
  • D：喪失のある孤立の例のうち exo=1 かつ喪失が孤立の後の割合。
  • E：047 の P1 の模型の U3・CASC・BIO の nmax の標本で E[P(L|nmax)] を出す（孤立の罰の上限：すべての生き残りが完全に孤立）。h_V5(s) = s·E_U3[P(L|nmax)] + (1−s)·h_conn（h_conn は 048 の χ≥0.5 の L_top の事後、点 0.20）。s ∈ {0, 0.25, 0.5, 1}。048 の道具（UNK = h·U1 + (1−h)·U2）で重み付きの A_Ord と重い崩壊からの割合を出す。大きさを無視した版（孤立の L の平均をそのまま使う）も並べる。
  • F（138）：E2、P1、P0、P2、P3、固定 M=3・10・30、048 の歴史の χ（CASC のみ）で A_Ord の h* を出す。
