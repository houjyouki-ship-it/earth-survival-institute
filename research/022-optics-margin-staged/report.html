主な数値

  • 方法の検証：収差のない系の格子限界は Abbe の 1/(1+σ) と 1〜6% で一致した。σ=0.3 の格子限界から求めた Zuylen 型の係数 k=λ/(d·NA) は 1.26（C_th=0.05）で、Zuylen の「照明を制御できない場合 1.3」と近い【計算と事実の照合。探索的】。
  • 良いレンズなら c≈1.4：収差なしでは c の中央値 1.46（10〜90% 1.32〜1.97）で、021 の [1,2] に収まる。2次元の乱数画素は、斜め方向の周波数と孤立画素のため、1次元バー（c≈1.08）より 1.3 倍太い線が要る。
  • 収差は c を急に大きくする（開口・焦点を固定した場合、中央値）：R=1 で 2.44、R=2 で 3.51、R=3 で 5.28、R=5 では 76% のセルで読めない。理由は、収差のある像は格子のコントラストが低いまま残る（低い C_th では格子が「分解されて見える」）のに、乱数画素では隣の画素の光が閾値を越えるため。全625セルでは中央値 3.13、[1,2] に入るのは 34% だけ。
  • 登録モデルの読取確率（Leeuwenhoek 級 d∈[1.35,4] µm）：線幅7倍で 0.41、10倍で 0.55、20倍でも 0.80。
  • 探索的：読者が絞りと照明を選ぶと c は戻る。開口を t 倍にすると球面収差は t⁴ 倍になる。R=5 のレンズでも開口を 0.67 倍に絞って R=1 にし、σ=0.6 で照らすのが最良で、c の中央値は全体で 1.45（10〜90% 0.62〜2.03）。読める確率は線幅7倍で 0.915、最小 s=7 で、021 の推奨と一致する（余裕はほぼない）。c<1 のセルは、格子の測定を絞らずに行った（d を悪く測った）場合に出る。
  • 探索的：段階書式（絞りを選ぶ読者、手引き 0.1 MB を線幅10倍・5複製で読める確率 0.991、面積はリールの 0.075%）：
  • 単層の D_max（P≥0.9）は 1.93 MB（線幅7倍・7複製）。
  • 手引きの成功で d'∈[1.1,1.6] µm になるなら、段階書式が単層を上回るのは P_g≥0.45。P_g=0.7 で 3.5 MB（1.8倍）、P_g=1 で 5.5 MB（線幅4倍、2.8倍）。
  • 悲観的な手引き効果 d'∈[1.35,2.3] µm では P_g≥0.5 で上回り、P_g=0.7 で 2.4 MB（1.26倍）。
  • 手引きの大きさ 0.03〜0.3 MB の違いは小さい（手引き層は 1% の 2〜23% を使う）。

批判的検討

  • 開口と焦点の固定は悲観的すぎる。登録モデルでは読者が収差を絞りで減らせない。Zuylen は、実際の使い手が照明や開口を絞ったと書いている【事実】。探索的解析では絞りだけで c がほぼ収差なしの値に戻るので、本当の問題は「読者が絞りを使うと知っているか」である【推測】。焦点の最適化は計算していない（さらに c を下げる可能性がある）。
  • c は d の測り方に依存する。格子を見えたと判断するコントラスト閾値 C_th を低く取るほど d が小さく測られ、c が大きくなる。歴史的な Nobert 試験板の判定基準は未確認で、C_th∈[0.03,0.2] は【推測】。
  • Nobert の刻線は位相物体に近いが、本計算は振幅格子で代用した。位相物体では見え方が変わる。
  • 雑音 σ_n と最適閾値は理想化。閾値は較正パターンで学べると仮定した。人の目が画素ごとにどれだけ揺らいで判断するかの実測は見つけていない。
  • 段階書式の d'（1.1〜1.6 µm）と P_g は推測。Zuylen の最適単レンズ計算値 1.11〜1.17 µm と Utrecht の実測 1.35 µm から幅を決めたが、手引きを読んだ人がそこまで到達できる確率の記録はない。習得年数は Piql の寿命（数百年以上）に比べ短いとみて入れていない【推測】。
  • 新規性：Leeuwenhoek 級顕微鏡の格子分解能を、部分コヒーレント結像の計算で「乱数の2値画素を誤り率1e-4で読める線幅」に換算し、収差と絞りの効果を QR フィルムの手読み層の設計につないだ計算は、確認した公開資料（Piql、GitHub Archive Program、Zuylen 1981）には見当たらない。

結論

良いレンズなら c≈1.4 で、021 の事前分布 [1,2] は妥当だった。ただし、収差のあるレンズを開けたまま使うと c は 2.4〜5 倍以上になり、線幅20倍でも読める確率は 0.8 にとどまる。読者が開口を絞れば c≈1.45 に戻り、021 の「線幅7倍・7複製・1%で約2 MB」がちょうど成り立つ。段階書式は、手引きの成功確率が約0.5以上なら単層を上回り、0.7 で 1.3〜1.8 倍になる（探索的）。

この結果を受けて、誰が何を変えるべきか

  • QR フィルム運営者（Piql・GitHub Archive Program など）：手読み層の先頭に、肉眼か虫眼鏡で読める大きさで「レンズの開口を、試験パターンの画素が分かれて見えるまで絞る」図と、太さを段階的に変えた2値の試験パターンを置くべきである。これがなければ線幅7倍でも読める確率は約0.4に落ちる（計算上）。さらに、0.03〜0.1 MB のレンズ作りの手引きを線幅10倍で置き、本体を線幅4〜5倍にすると、手引きの成功確率が約0.5を超えれば単層を上回り、0.7 なら同じ1%で 2.4〜3.7 MB（単層 1.9 MB）に増やせる（探索的）。
  • 本研究所：021 の一行推奨は「読者が絞りを使える」前提つきとして残し、絞りの手順と試験パターンを必須の付属物にする。
