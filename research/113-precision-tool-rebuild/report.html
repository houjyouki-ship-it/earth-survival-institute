問い

112 で、資本で縛るのは T2e の段の精密な道具（平面・ねじ・目盛り）だけと分かり、F_heavy（遅い κ）は道具を作り直せないなら 1.07、作り直せるなら 2.43 だった。どちらに近いかは「作り直しに要る社会の大きさ N_tool」が N_T2e よりどれだけ小さいかで決まる。

方法

  • T2e の道具の条件を「群の人口が N_tool に達した時点で作り直せる。それまでは廃墟の道具（107 の Myford、中央値 70 年）でつなぐ」とした【独自仮説】。t_tool = max(0, t_below − ln(N_T2e/N_tool)/r_pop)、条件は min(t_below, t_tool) ≤ L。N_tool ≥ N_T2e なら 112 の X と同じ、N_tool=1 なら 112 の R と同じになる。製鉄・レンズは 112 の data_main をそのまま使った。
  • N_tool の版：事例の社会の人口（最小 5.2×10⁶、England 1801 の 8.29×10⁶）、その 1/10、工房の規模（10³〜10⁵ の対数一様、10⁴）【推測】、比 c = N_tool/N_T2e の走査（10⁻⁴〜1）。
  • 模型の N_T2e は 5〜95% で 6.0×10⁵〜4.5×10⁶（中央値 1.8×10⁶）【計算】。

批判的検討

  1. 事例は N_tool の上限しか与えない。 7 件はすべて 500 万人以上の社会で起きたが、これは「初めて発明した」場所で、需要（時計・航海・蒸気機関）と職人の数が多い社会に発明が集まるのは当然である。手順を知った小さな群がいくつの人数で作り直せるかの下限には何も言えない。H125a の支持は選択の効果と区別できない【推測】。
  2. 一方で、三面の方法は「より精密な基準を要らない」と明記されており、Ramsden は自分の盤からより正確な盤を作った。知識さえあれば、外の工場なしに精度を自分で上げられる経路は資料で確かめられた。ただし前提には鋳鉄の平板、焼き入れした削り刃、時計の歯切りの技能（Hindley）があり、これらは T2e より下の段（製鉄・鋳物）に乗る。
  3. 結論の幅は、上の 2 点の間でどこに N_tool を置くかでまるごと決まる：事例の大きさなら 1.07、1 桁下で 1.21、工房の規模なら 1.9〜2.0。資料を足しても今回の種類（発明の年表）では幅は縮まない。縮めるには「外からの道具なしに、手順の知識を持つ小さな集団が精密な道具を作り直した例」が要る。
  4. 二重の数えの判定：比 c が 0.1 以上なら N_tool は N_T2e と同じ桁で、R の版（2.43）は N_k と二重に数えている。c が 0.1 を下回るのは工房の規模の版だけで、それは【推測】である。よって 112 の R の版は、根拠のある版としては扱えない。
  5. 模型の N_T2e（中央値 1.8×10⁶）自体が、史実の発明の社会（5〜10×10⁶）より小さい。N_T2e の較正（024・038）が楽観である可能性もある【推測】。
