批判

  1. 結果の大半は算術に近い：D_C の平均 185 年は定義A に含まれていた 200 年とほぼ同じなので、E1 が 2.17 に戻るのは予想どおり。本当に決まっていないのは「現代の重い崩壊（核の冬・人工の疫病）で、模型の生き残りの数 n が谷の値か、谷へ向かう途中の値か」で、これは史実の表からは決まらない【推測】。
  2. 下り坂は C 型（国家・交易の崩れ）で長い。模型の重い崩壊がどちらの型に近いかで D は 0〜200 年動く。破局の死が数年で済む型（S 型に近い）なら D_S を使う E2 系と主の E1 の差は小さい（+1.3 %）が、D=0 の定義B（1.90）とは大きく違う。つまり効くのは「停滞する標本に C 型の下り坂を付けるか」の一点【独自仮説】。
  3. Copán の 425 年は谷の年＝打ち切りの年（1200）で、下り坂というより放棄までの年数。E3 は上の感度としてだけ使う。Easter（155 年）は移入ありで接触による S 型に近い面もある。
  4. 下り坂と停滞は同じ事例から引き、pick と独立に引いた（E1）。対にした E4 は定義A と一致するので、独立か対かの差（2.149 対 2.174）は小さい。
  5. W 形（段の喪失の判定に停滞を入れない）だけで回した。下り坂の間に技能が衰える効果（WT 形）は見ていない。
