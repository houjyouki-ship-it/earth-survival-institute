批判的な検討

  • τ1 の根拠は遠い場所 2件だけで、どちらも文字の社会（Norse）だった。文字の記録があっても正確な位置は数百年以内に失われたので、重い崩壊（口伝だけ）ではもっと短いかもしれない【推測】。逆に、2件とも小さな入植地で、金庫は「Svalbard」という地名と結びつくので、地名が残れば τ1 は長い【推測】。
  • pointer の効きは、写しの1部が見つかり読まれる確率（0.3〜0.84）と相関 c（0.5〜0.95）にほぼ全面的に依る。戦乱で図書館が丸ごと失われる例（060 の Załuski 0.92）からは c はもっと高いかもしれず、その場合 100部でも効きは小さい。最大の未知（→164）。
  • pointer は「金庫まで行ける」r（0.5〜1）を掛けている。T2 の社会が 78°N に船で届くかは確かめていない（→165）。
  • 目印の費用は Guidestones（下限）と Seed Vault の建設費（施設全体）からの推測で、WIPP の文書に費用の数字はなかった。目印の寿命 τ_M は人の破壊（Guidestones の爆破）と崖の碑文（Behistun 約2,500年）の間で、推測の幅が大きい。
  • CE の比較は TC がある前提の上乗せ。pointer と S_TC は排他でなく、南半球の写しや法定納本の紙に座標の1ページを足すのはほぼ費用0なので、実際の提案は「両方」になる。

新規性

WIPP の PIC は現地の標識と記録の分散を並べたが、両者の効きと費用を同じ物差しで比べてはいない。Memory of Mankind は座標の token を配るが、その効きを見積もっていない。文明の回復の年数と場所の忘却を掛け合わせ、目印と座標の写しの費用あたりを金庫の手引き・南半球の写しと同じ物差しで比べたのは本研究所で初めて【推測：網羅的に調べたわけではない】。

この結果を受けて、誰が何を変えるべきか

金庫の運営者（Svalbard の Arctic World Archive など）は、記念碑のような目印に数百万ドルをかけるより、正確な座標・道順・地図を耐久紙に刷った冊子を 100部以上の図書館・公文書館に預け（約 $4万）、南半球の写しと法定納本の紙にも同じページを入れるべきで、費用あたりは目印の約55倍、南半球の写しの約2.5倍。本研究所は 060 の「目印で 0.96 に戻る」を「永久の目印の仮定」と改め、τ1 の主を遠い場所の事後（中央値 64年）に寄せて重い崩壊の金庫の価値を 0.42倍と記録する。
