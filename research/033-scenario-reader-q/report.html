研究033：読者の RAM で q を決めると、提言の順位は崩壊シナリオで変わるか（open_problems 99）

問い

批判的検討

  • H45b の棄却は、032 の恒等式がまだ半分残っていることを意味する。C は T か H がないとほぼ無価値なので（C だけの限界値は 0.00002〜0.005）、Shapley は束の価値をほぼ半分ずつ分ける。だから C/T は束の中の小さな非対称（RAM の分布）でしか動かない。補完財の「順位」は、そもそも問いとしてずれている。意味があるのは「T＋C を束で入れるか」と、束と S の比較である。
  • S の優位は大半が水増し。T3 が残る社会でも金庫の中身を価値1で数えている（032 と同じ扱い）。計算機の社会が残れば手元のデータもかなり残るはずなので【推測】、主に読むべきなのは T3 を除いた値（S と束がほぼ同じ大きさ）。S の費用（新しい拠点）は T・C（板数枚、約4リール）よりずっと大きいので、費用あたりでは束が勝つ可能性が高い【推測、費用は未計算】。
  • マイコンの値は確認したが、回収の確率は推測。p_salv、電子部品の寿命、f_mcu は根拠がない。感度では順位は変わらないが（回収なし・マイコン経路なしでも S＞C＞T＞H）、BIO の探索的な逆転はこれらに依存する。
  • c4 の組み合わせ規則（noisy-or か max か）は結果をほとんど動かさなかった（Shapley の差 2% 未満）。
  • H45e の支持は、032 の割り引きが q の置き方に頑健だという意味ではない。T だけの絶対値は 032 の約1/5 に下がった。比が保たれたのは、GEN0 の T も同じ q で計算し直したから。

結論

q を読者の RAM で決め、RAM を再出発の状態に依存させても、板の手引き（T）・手読み層の控え（H）・小窓版（C）・第2拠点（S）の順位は、崩壊シナリオによって変わらなかった（5シナリオすべて S＞C＞T＞H）。順位を変えるのは、手引きで作る読取装置の RAM（144 KiB を超えれば T＞C）である。もっと大事な訂正は、032 が板の手引きを単独で評価していたことである。手引きだけでは 1950 年代前半級の読者は XZ をほとんど開けず、重み付きの価値は 032 の約1/5（0.0025〜0.0036）しかない。小窓版と束にすると 0.021〜0.047 になり、032 の板の値の約2.6〜2.8倍になる。

この結果を受けて、誰が何を変えるべきか

  • GitHub Archive Program・Piql などの運営者：板の手引きと高層全体の小窓版（dict=4KiB,lc=0、約4リール）は、片方だけでは効かないので必ず一緒に入れる。手引きだけを足すなら、価値は小窓版つきの約1/20 しかない（GEN0 で 0.0116 対 0.238）。
  • 本研究所：今後の提言の比較は単独の限界値ではなく、束か Shapley 値で行う。032 の「板の手引きの重み付き ΔV 0.008〜0.018」は、「小窓版なしなら 0.0025〜0.0036、小窓版つきの束なら 0.021〜0.047」と読み替える。

既存研究に対する新規性

Ord と XPT は崩壊の原因別の起きやすさを出すが、崩壊後の読取技術も、知識保存の提言どうしの補完関係も扱わない。本研究は、マイコンの RAM という確認できる値で回収した電子部品の読者を定め、知識保存の4つの提言を協力ゲームとして Shapley 値で比べ、順位を決めるのが崩壊シナリオではなく読取装置の RAM であることを示した。この組み合わせは、確認した資料（Ord、XPT、Xia 2022、GitHub GUIDE、025・028 の資料）には見当たらない。
