研究075：到達の指標 A と重い崩壊の TC/V0 の対応、部数 N を含めて

注：TC/V0 も A も生存確率・復興確率ではない（TC/V0 は 060〜071 の模型の中の価値の比、A は届く範囲に生き残った写しがある生存者の重みの割合）。提言は模型の中での順位で、外部の検証はまだ。

問い（open_problems 191＋194）

072〜074 は届くかだけを数える A で置き方と部数を比べた。読める確率・群の数・時間を含む 070/071 の重い崩壊の TC/V0 で、(1) 置き方の順位は A と同じか、(2) 部数 35→200 で TC と費用あたりはどう動くか。

方法

  • 070 の sim.py を「版」の前まで exec し 070 の主（重い崩壊 0.81913）を差 0 で再現（assert）。074 の sim.py を「仮説」の前まで exec し、074 の versions と mesh_curve を差 0 で再現（assert）。
  • 重い崩壊の標本で、070 の「群が届く単位の数 D」を「群の点から届く距離 r 以内の写しの数 n」に置換。群の数 G・地理（xia150・xia47・pop）は 070 の乱数、群の点は 074 の点の重みから引く（seed 20261075）。r の主は 073 の kmov（Binford 261群）から標本ごとに1つ、版は群ごと・×2・071 の19件。写しは1か所1部（mu=1）、軽い崩壊は S_ind(T, N, N)。
  • 費用あたり：070 と同じ式 ΔTC/TAB×C_T/(C_P(N)+C_pr(N)+C_map(N))、primer と地図の印刷費は部数に比例（主）。版として 070 と同じ 100部分の固定費。
  • 資料：本回は新しい外部資料を開いていない。使った資料は 069〜074 で開いて確認したもの（Natural Earth の点、Binford/CRAN binford、071 の19件、Xia 2022 S5 ほか）で、各研究の sources/ にある。

仮説の判定（すべて計算前に登録した予測）

  • H87a（τ ≥ 0.7）：棄却（0.689）。食い違いは cover3000x（A は下から2番目、TC は中位）と pop@cty・surv150（A は中位、TC は上位）。TC の標本は 070 の3地理の平均で避難所の地理（refuge）と最悪値を含まないため、A の minimax regret の最良 per_subregion は TC の平均では5位。
  • H87b（200部の費用あたりが 35部の 0.5倍未満）：支持（0.40、点推定 0.4）。
  • H87c（35→200 で重い崩壊の TC +0.03 以上）：支持（+0.049）。
  • H87d（mesh35 が 070 の主より 0.05 以上低い）：支持（0.680、差 0.139）。
  • 費用あたりが最大の N（記述、支持に数えない）：全体は走査の端の 20部、重い崩壊は 35部。

批判的な検討

  • TC の差の大部分は床（写しに届かなくても残る価値 0.638）に埋もれ、置き方の差 0.026 は 070 の版の幅（0.027）と同じ程度。置き方の順位を TC で決めるのは無理で、TC の上では「部数と届く距離」の方がはるかに効く。
  • 費用あたりは平均の比で、限界の費用あたり（35→200 の追加分）は出していない。比例の費用では平均は単調に下がるので、限界はさらに低い。
  • 群の点を生存者の重みから独立に引き、写しの近くに人が集まる効果（写しを持つ町に生き残りが寄る）は入れていない。入れると TC は上がる（推測）。
  • mesh は kmov の届く距離に合わせて作った置き方で、kmov で評価すると有利になる（074 と同じ注意）。

誰が何を変えるべきか（模型の中での順位、外部の検証はまだ）

金庫・冊子の運営者は、崩壊後の移動が狩猟採集民の規模になる場合、35部の置き方の工夫（TC で ±0.013）に時間をかけず、部数を増やすか（200部で +0.049）、写しを生き残りが集まりそうな場所の近くに寄せる方を検討する。ただし部数の費用が比例で増えるなら費用あたりは 200部で 35部の 0.4倍になるので、部数は費用の構造（印刷費の比例分と固定分）を確かめてから決める。本研究所は 074 の「35部→200部で A は約4倍」を「TC では +0.05、床と天井の差の 19%→42%」に改める。
