問い

067 で、重い崩壊（機械が止まり T1・T0 から再出発）の後の社会が座標の冊子と primer（絵の読み方の手引き）に取り組むのは「学問の段 P」に入ってからと置き、P が T2（読取装置を作れる段）より Δ 年先なら primer の価値が戻る（Δ=0 で 0.813、Δ≥400 で 0.851、Δ_half 34年）と分かった。本回は P を二つに分けた。 - R1（文献学の段）：読める文字の古い文書・碑文を体系的に集め・写し・比べ・誤りを正す。 - R2（読めない文字への体系的な取り組み）：067 の onset。 そして 5つの社会で R1 と L（望遠鏡・顕微鏡の級のレンズをその社会で作った年）の順を数え、R1 の段にある社会が L より前に、見えていた読めない文字に取り組んだかを数えた。

結果1：文献学の段はレンズより何百年も先に来るが、読めない文字への取り組みは起こさない

  • R1 は 5社会すべてで L より前（Δ1 = 107、187、503、≥758、≥795年、中央値 503）【計算】。067 の P を R1 と読めば Δ は Δ_half（34年）を大きく超える。
  • しかし R1 の段にある社会が L の前に読めない文字を見ていた 1,705 社会年で、体系的な取り組みは 0件【計算】。Jeffreys の事後で R1 の段の取り組みの時定数 τ1 の中央値は 7,472年（90% 884〜85万年）。067 の前近代の時定数 5,874年と区別できず、鍵ありの読みの τ_key（65年）の 115倍。
  • 唯一 R2 に達した Europe では、R2（1616 の Palmyrene の碑文の印刷）は R1 の 195年後、望遠鏡（1608）の 8年後（alt の Kircher 1643 なら 35年後）。Δ2 = L − R2 = −8年で、R2 は T2 より先に来なかった【計算】。
  • 【推測】読めない文書に取り組むかは「古い文書を大事にする学問」があるかでは決まらず、欧州でレンズと同じ時期に来た別の何か（印刷・収集・解読を競う学会など）と一緒に来た。この標本では R2 と T2 は同じ一揃いの中にある。

批判的な検討

  • 切り替えの規則を守らなかった：next_plan は「欧州以外で両方の年が決まる社会が 3 未満なら B へ」と決めていた。点で決まるのは 2社会で、規則の字面では B に移るべきだった。本回は L が「1608 より後」と本文で決まる Abbasid・Byzantine を打ち切りとして数え A を続けた（事前登録に書いた逸脱）。主の結論（H80b）は Δ の分布でなく曝露と件数に乗り、曝露 1,705 年のうち 1,048 年はこの 2社会から来る。打ち切りの 2社会を除くと E1 は 657 年で τ1 の中央値は約 2,890年【計算：本回の別計算、Gamma(0.5, 1/657) の中央値の逆数】、それでも τ_key の 40倍以上。
  • 非欧州の L は伝播：China の 1635 と Japan の 1790 は欧州の望遠鏡を知ってから作った年で、独立に作る年はもっと後か、なかったかもしれない。Δ1 はどちらも下限で、R1 の楽観の版をさらに楽観にする向きにしか効かない。主の版は Δ1 にほとんど感応しない（0.8125〜0.8128）。
  • 「取り組みがない」の証拠は弱い：Byzantine と Khitan の 0件は Wikipedia の本文に記述がないことによる。中世の Islam の 9〜10世紀の試み（067）は体系的でない試みとして数えていない。どれか 1件を体系的と数えても k1 の版（τ1 中央値 1,446年、0.817）の程度。
  • 標本は R2 の一つの出来事：R2 に達したのは Europe だけで、R2 が T2 と同じ一揃いに入るという読みは 1件の上にある。ほかの社会は L を独立に得る前に欧州とつながったので、R2 と T2 の順が独立な社会で何回見られたかは 0回。
  • 冊子は遺跡の碑文と違う：冊子は読まれるために作られ、R1 の社会は「読める文字の古い本」を大事にした（考証学は甲骨を数か月で読み始めた）。冊子が後の社会にとって「自分の文字の祖先」に見えれば R1 の段で読まれうる。ただし重い崩壊の後で文字が切れた後の社会にとっては、冊子の文字は外国の文字である（064・065）。
  • 軽い崩壊（計算機の社会が残る）では文字が続くので primer は使われず 0.969 で不変。

新規性

文献学の段とレンズの段の順を欧州と非欧州の5社会で並べ、文献学は 107〜800年先に来るのに、その段の社会が読めない文字を見ていた 1,705 社会年で体系的な取り組みが 0件だったことを示し、「学問の段が先に来れば primer が戻る」という 067 の逃げ道を、学問の段を二つに分けて塞いだのは本研究所で初めて【推測：網羅的に調べたわけではない】。【独自仮説】読めない文字への取り組みは、レンズ・印刷・学会と同じ「科学の一揃い」と一緒に来る。重い崩壊の後の社会にとって、primer が読まれるのは T2 とほぼ同時かその後で、T2 までに冊子を使わせるのは「読まずに使える部分」だけ。

この結果を受けて、誰が何を変えるべきか

金庫の運営者は、primer を「文献を大事にする前近代の学者が解いてくれる」ことに期待して予算を割くべきでない（費用あたり 1.8、冊子の配布は 44）。予算は冊子の部数と別々の預け先に回し、座標と道順は文字を読まずに使える形（地図、方位、数の絵）で冊子の最初に載せるべき【推測】。本研究所は 067 の「Δ 次第で 0.813〜0.851」を「学問の段を二つに分けると Δ は R2 で −8年、重い崩壊は 0.813（版 0.813〜0.821）」に改め、179 の線は閉じる。次は文字なしで伝わる部分の割合（180＋176）へ進む。
