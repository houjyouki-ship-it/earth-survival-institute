研究138：無傷の国の T3 保持と征服の圧力の相関（open_problems 319）

注：F_heavy・c_C・q_T3 は模型の中の量で、生存確率でも復興確率でもない。提言は模型の中での順位で、外部の検証はまだ。

問い

137 は NUC_G（150 Tg）の F_heavy の主を 1.962 としたが、これは「無傷の国が T3 を失うのに遠征はする」組み合わせを含む。無傷の 4 か国が T3 を保つ割合 q_T3 を発電の国内自給で置き、(1) 032 の NUC_G の T3 保持 0.80 と突き合わせ、(2) 重い崩壊の標本（4 か国とも T3 を失った標本）の中の条件付きの P_ext・F_heavy を出す。

資料（本回開いて確認、sources/README_sources.txt）

  • 【事実（OWID energy-data、2024 年、TWh）】発電量：Argentina 152.51（ガス 81.95、再生可能 52.44、原子力 10.45、石油 6.36、石炭 1.31、純輸入 9.17）、Australia 281.64（石炭 127.33、再生可能 98.79、ガス 49.10、石油 6.42）、Sri Lanka 17.07（再生可能 9.43、石炭 5.61、石油 2.03）、Dominican Republic 24.03（石炭 7.20、ガス 7.00、石油 5.30、再生可能 4.53）。
  • 【事実（同）】燃料の生産/消費（TWh）：Argentina ガス 441.1/456.2、石油 682.0/339.0（石炭の生産は欠測）；Australia 石炭 3,282.6/423.0、ガス 1,501.4/369.9、石油 173.4/620.5；Sri Lanka は生産の列が欠測（石炭の消費 19.4、石油 64.8）；Dominican Republic は生産・消費とも欠測。

方法（analyze.py、約 1 秒）

PREREGISTRATION.md（17:35 JST、資料の前）どおり。d = (再生可能 + 原子力 + Σ 火力×min(1, 生産/消費)) / 発電量、主の q_T3 = d。重い崩壊の上限は 4 か国とも T3 を失う確率（独立 Π(1−q)、完全相関 min(1−q)）。条件付きの P_ext = π·P_ext(137 の主) + (1−π)·P_ext(全員が拠点の距離)。再現：137 の主の P_ext 0.2370 と差 0 を assert、134 の cC_curve を assert。

逸脱

Sri Lanka の 2024 年のガス発電の列が欠測で、0 として埋めた（登録には生産の欠測しか書いていない。2021〜2025 年すべて欠測で、ガス火力を持たない扱い）。Argentina の石炭の生産の欠測は登録どおり 0（実際は小さな産出がある【推測】ので d は下限寄り）。

批判的検討

  • d は T3 の必要条件の一部でしかない。電力があっても、半導体・交換部品・通信の輸入が止まれば計算機の社会は年単位で摩耗する【推測】。だから Q 0.98〜1.0 は上限で、032 の 0.80 が誤りとはまだ言えない。ただし 032 の 0.19 を正当化するには、電力以外の理由（部品の輸入の途絶、無傷の国自体への攻撃、交易ありの表で無傷の国が変わること）が要ると分かった【独自仮説】。
  • 4 か国の T3 の喪失は独立ではない（同じ世界の交易の途絶が原因）。完全相関の版でも上限 0.016〜0.026 で、結論の向きは変わらない。
  • 重い崩壊の標本の中での Argentina の遠征の確率 π は資料で決まらない。T3 を失った Argentina は燃料・船の整備も失っている側【推測】で、π は 1 より小さい側に寄る。そのとき F_heavy は 137 の 1.962 から 1.93〜1.95 へ下がるが、差は 0.03 以下。
  • 2024 年の平時の量で、核の冬の後の水力（雨の減少）や需要の低下は入っていない。

誰が何を変えるべきか（模型の中での順位、外部の検証はまだ）

模型の維持者は NUC_G の F_heavy を 1.93〜1.96（主は π=0.5 の 1.954、π は未決）とし、征服の圧力の系列（135〜138）はここで閉じる（本回の動きは 0.01〜0.03）。より大きいのは 032 の NUC_G の重い崩壊の重み 0.19 で、発電だけなら 0.03 未満になる。次は「無傷の国が部品の輸入なしに計算機の社会を何年保つか」を公開の故障率の資料で確かめ、この重みを置き直す。D2rz の推しは不変。
