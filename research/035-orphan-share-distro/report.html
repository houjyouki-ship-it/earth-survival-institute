研究035：配布系と手元の写しで、金庫の中身のどれだけを補えるか（open_problems 104・105 の一部）

注（2026-10-21、外部査読への対応で追記）：本報告の価値・V/V0・TC（V0 比）・A などの指標は模型の中の量で、生存確率でも文明の復興確率でもない。「誰が何を変えるべきか」などの提言は模型の中での順位で、外部の検証はまだ。

問い

034 の順位（南半球の第2拠点 S 対「板の手引き T＋小窓版 C」の束）は、金庫の中身のうち計算機の社会（T3 保持）の手元の写しで補えない割合 f_orph でほぼ決まり、交差点は A_XPT_S で 0.37、A_XPT_E で 0.087 だった。034 は f_orph を根拠なしに logU[0.003, 0.3] と置いた。本研究は、(1) Linux 配布系 Debian が金庫の中身をどれだけ収めているか（測定）、(2) Debian の鏡像の地理（測定）、(3) 開発者の手元の写し（推測の係数）から f_orph を見積もり、034 に戻す。

批判的検討

  • 034 の f_orph の仮置きは小さすぎた。034 は中央値約0.03 と置いたが、配布系の収録と手元の写しを数えても依存重みで約0.12、星重みで約0.47 になる。星重みが大きいのは、人気の repo（awesome 系、教材、アプリ）の多くが配布系に入らず、依存されないので手元に写しが散らばらないため。これで 034 の「束が第2拠点を上回る」は A_Ord の重みでしか保てない。
  • 最大の未知は a（写しが生き残り見つかる割合）で、Debian の鏡像の生存 p_m はほぼ効かない。南半球にも source 付きの鏡像が 25件あり、1件でも残れば収録分は届くので、p_m を 0.2〜0.9 で動かしても結果は変わらない。逆に、a は 10⁻⁵〜10⁻² の推測で、ここに根拠がない。
  • H47d の棄却は模型の作りによる。全面核戦争で南半球に限ると、開発者の割合が小さいので手元の写しが減るが、鏡像は十分あるので差は 1.2倍にとどまった。他の5つのシナリオは地域の平均を同じに使ったので、シナリオ間の差は出ない（模型の制約）。
  • g（パッケージに欠ける価値）が床を作る。npm のパッケージは変換後のコードだけのことがあり、履歴や試験も欠ける。g を 0〜0.5 と置いたのは推測で、A_XPT_E の結論（手元の写しをいくら増やしても S が上）はこの床に依存する。
  • 照合は名前規則に頼る部分がある（M2 のみの一致は依存重みの約3割）。精度で割り引いても 70.2% で、H47a の結論は変わらない。Debian の版が金庫の版（2020年）と違う問題は v（0.7〜1.0）で粗く扱っただけ。
  • 星重みの母集団は ≥20,000 星の 1,368件だけで、金庫全体の星重みの代表かは確かめていない。

結論

Debian は金庫の中身の依存重みの約73%を収め、source 付きの鏡像は南半球にも少なくとも25件ある。そのため、依存で重みを付けると、計算機の社会が手元の写しで補えない割合 f_orph は約0.12で、034 の交差点（A_XPT_S 0.37）より小さい。しかし星で重みを付けると収録は約18%しかなく f_orph は約0.47、半々では約0.30になる。034 に戻すと、第2拠点が束を上回る確率は A_XPT_S で 0.43、A_XPT_E で 0.94 になり、034 の「束が上」は Ord の重みでしか成り立たない。残る最大の未知は、手元の写しが生き残り見つかる割合 a である。

この結果を受けて、誰が何を変えるべきか

  • 南半球の大学や国立図書館（第2拠点の候補）：新しい拠点を置くなら、Debian がすでに広く写している依存の部品ではなく、配布系に入っていない人気の repo（星の上位）を優先して入れる。依存の部品は Debian の鏡像（豪州・ブラジル・チリなどに25件以上）が代わりを果たしている。
  • 本研究所：034 の f_orph の仮置き（logU[0.003, 0.3]）を撤回し、依存重みで約0.12、星重みで約0.47 を使う。032〜034 の順位は「Ord の重みでは束が上、XPT の重みでは第2拠点がほぼ同等か上」と読み替える。

既存研究に対する新規性

Ord と XPT は崩壊後に残る写しを扱わない。Software Heritage や GitHub Archive Program の資料は写しを増やす理由を述べるが、既存の配布系（Debian）が人気・被依存の repo をどれだけ写しているかは測っていない。本研究は、金庫に入った依存の重い部品の約73%が Debian に収められ、星の上位は約18%しか収められていないことを測り、この差が第2拠点と知識保存の束の順位を決めることを示した。この組み合わせは、確認した資料（Ord、XPT、Xia 2022、GitHub GUIDE、Software Heritage、Internet Archive、Debian の鏡像一覧、Octoverse 2024）には見当たらない。
