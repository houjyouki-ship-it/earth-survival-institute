方法（sim.py、seed 20261044、約32秒、ネット接続なし）

  • 事前登録：PREREGISTRATION.md（2026-10-18T10:39Z、初回実行前）。
  • A1：上の2本の総説が「今ある病巣」として名を挙げた28か国（厳しい一覧）と、隣接・過去の病巣・Transcaucasia・Iraq・中央アジアを足した41か国（広い一覧）の人口の割合 S_c。
  • A2：India の国全体の減り −ln(1−死者/人口)/年数。死者 1,000〜1,200万、人口 2.55億〜3億（3億は【推測】の上側）、年数 25〜63年（63年は 1897〜1960年、25年は【推測】の短い窓）。
  • B：042 の sim.py を exec して乱数と関数をそのまま使った。r(n) = b − d(n)：
  • b = r_F。p_other が当たれば b = r_F − ρ·(r_F − r_E)、ρ ~ U(0.16, 0.57)（043 でペストの再来が差の 43〜84% を説明した残り）。原因の病原体の再来は 042 と同じく r = r_E。
  • 集団の土地に病巣がある確率 φ·S_c（φ ~ U(0.1, 0.6) は国の中で病巣の地域に住む割合【推測】、NUC_G でオーストラリアが最大の集団なら 0）。あれば d = D_max（集団の大きさによらない）。
  • 病巣がなく、病巣の地域と交易でつながる確率 p_link ~ U(0, 1)【推測】。つながれば d = D_max·n/(n+N_c)、N_c ~ logU(81,805, 1e7)（043）。どちらでもなければ d = 0。
  • D_max = λ_max·(−ln(1−m))、λ_max ~ U(0.061, 0.118)（Sweden〜England）、m ~ U(0.10, 0.20)。
  • r が 0.0005/年を下回る標本はそこで止めた（U3 で 7.2%）。
  • 確認：同じ待ち時間の関数で 043 の連続版（B2）の U3 の TAB を誤差0で再現（check_043_B2）。
  • 再現：/tmp/rep044b/ で再実行し、results.json は runtime 以外一致（葉 239個、差分0）。

批判的検討

  • 【推測】H56d の棄却が本回の主な発見。重い崩壊の集団は数千〜数十万人と小さく N_c（8.2万〜1e7）より小さいことが多いので、交易でつながってもペストはあまり戻らない。効くのは「地元に病巣があるか」（φ·S_c）と「あったときの減りの大きさ」（D_max か India 並みか）で、043 の「遠くからの船や荷の隔離を先に」は重い崩壊ではあまり効かない方向に修正が要る。
  • 【推測】ただし地元の病巣で d が集団の大きさによらないと置いたのは強い仮定で、φ と D_max がトルネードの上位に来たのはこの仮定のせいでもある。小さな集落に鼠が住みつくには穀物の貯えと定住が要るので、地元でも小さな集団では弱い可能性がある（未検証）。
  • 【推測】India の数字は抗菌薬の前（1937年以前）だが、ワクチン（1897年以降、1900年頃までに 400万人に接種）と検疫のある時代。T1・T0 の社会の局所の減りの代わりには使えず、上下の幅として扱った。
  • 【推測】生き残る集団の居場所を人口に比例と置いた。核の冬（NUC_G）以外のシナリオで南半球や島に偏るなら S_c は下がるが、トルネードで S_c の一覧の差は小さく（0.0002）、φ の幅の方が効く。
  • 【推測】止めた（0.0005/年）標本が U3 で 7%。止めの値を変えると TAB が動く可能性がある（未確認）。
  • 軽い崩壊（計算機の社会が残る）は人口待ちがないので、本回の変更の影響を受けない（作りから）。重み付きの変化（1.07倍）はすべて重い崩壊から来る。

この結果を受けて、誰が何を変えるべきか

本研究所は f_foci の既定を「φ·S_c（S_c=0.586）＋交易でつながる場合の飽和型」に改め、次は地元の病巣のもとでの減り D_max（1回の死亡率と頻度）を絞る。金庫の運営者は、重い崩壊向けの手引きに疫病対策を入れるなら、遠くからの船や荷の隔離より「病巣の地域（中央・東アジア、India、東・南アフリカ、米州の西部）で野生の齧歯類と穀物の貯えを住まいから離す」方を先に検討する価値がある【推測】。
