批判的な検討

  • 消えた例はどれも、読み書きが少数の書記・支配層に限られ（Linear B の書き手は1宮殿に数十人）、その用途か担い手が局面で消えた例だった。読み書きが普通の成員に広がっていた2件（Pitcairn の 19人、Cherokee の強制移住）はどちらも続いた。ただし broad は2件しかなく、喪失の事後は 5〜95% で 0.01〜0.58 と広い【推測】。
  • 現代の読み書きは 87% と広いが、学校という制度で教わる。学校が消えたとき、家庭や宗教で教え続けるなら broad に近く、制度とともに消えるなら Linear B の書記に近い。この重み w が、本回の版の中で一番大きく値を動かした（0.77〜0.83）。w の根拠は本回の資料にはない【推測】（→172）。
  • 周りに文字の社会がない 2件（Pitcairn は続き、Rapa Nui は消えた）だけにすると 0.77 まで下がるが、2件は広さが正反対で、周りの社会の有無と広さを分けられない。
  • 3つの独立な群のどれか1つが保てば広まる（G3）なら 0.86 まで上がる。重い崩壊の生き残りがいくつの互いに独立な群に分かれ、文字が群の間で広まるか（Greek が Phoenician の文字を取り入れたような）が、w の次に大きい未知（→173）。
  • 漂いの率は、続いた例の 6,322年で喪失 0 から出したもので、続いて記録に残った文字だけを数えている（消えて記録もない少数の文字は数えられない）。漂いの効きは 0.004 と小さいので、この偏りで結論は変わらない。
  • 本回の主（0.803）は 063 の主（0.814）とほぼ同じで、すべての版は 0.77〜0.86 に入り、063 の p_cont の走査の幅（0.67〜0.87）の内側に収まった。事例の数え上げで p_cont をこれ以上絞るのは難しく、冊子の価値を上げるには、文字が続く確率を当てにしない手（読み方の手引き primer、→170）の方が効く【推測】。
  • 弾圧の 3件（喪失 2/3）は外からの禁止・没収による喪失で、地球規模の崩壊には当てはまらないとして主から外した。入れても 0.803 で変わらない。
  • 符号は一人の判断で、広さ不明が deep の半分（5件）を占める。不明をすべて片側にしても 0.786〜0.811。

新規性

崩壊の後に文字が続くかを、その文字を教える人が共同体の中にしかいない例（少数の宗教集団・孤立した島・書記の文字）に限って数え、読み書きの広さで分け、保存の写しの価値に入れたのは本研究所で初めて【推測：網羅的に調べたわけではない】。【独自仮説】崩壊を越えて文字を消すのは人数の少なさより読み書きが少数の役目に限られていることで、現代の読み書きが崩壊を越えるかは、学校なしで家庭や宗教の場で教え続けるかで決まる。

この結果を受けて、誰が何を変えるべきか

金庫の運営者は、座標の冊子を図書館だけでなく、学校が消えても読み書きを教え続けそうな場所（教会・モスク・寺の図書室など宗教の場）にも預け、子どもに文字を教えられる絵入りの読本を冊子に添えるべき（Pitcairn では聖書がその役を果たした。読み書きが広く続く見込み w が 0 から 1 になると重い崩壊の価値は 0.77→0.83）【推測】。本研究所は 063 の p_cont 0.70 を「局面で 0.63、T2 の時点で 0.59、重い崩壊の冊子の価値 0.80（版で 0.77〜0.86）」に改め、事例の数え上げの線はここで止め、次は読み方の手引きの効き（170）へ進む。
