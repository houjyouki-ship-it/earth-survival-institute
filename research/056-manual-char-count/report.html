注（2026-10-21、外部査読への対応で追記）：本報告の価値・V/V0・TC（V0 比）・A などの指標は模型の中の量で、生存確率でも文明の復興確率でもない。「誰が何を変えるべきか」などの提言は模型の中での順位で、外部の検証はまだ。

批判的検討

  • 数えた本は当時の読者向けで、前提知識（読み書き、算術、度量衡、道具の名前）を書いていない。m_tacit U(1,3) は根拠のない幅で、上端なら CH_heavy はほぼ 3,000万字になる。逆に 1800〜1920年代の本は今の目で見ると冗長な部分（歴史、宣伝、統計）を含み、要約すれば短くなる。
  • 段の選び方は 10段で、繊維・紙・印刷・測量・船などは m_cover U(1,2) に押し込んだ。GVCS の 50種の機械を基準にすれば足りない恐れがある。
  • Ure の項目の切り分けは近似で、取りこぼした見出しは前の項目に入る。De Re Metallica には Hoover の脚注（段落の頭が [n] のもので約 22万字、約12%）と付録が入る。
  • 図の量は数えていない。De Re Metallica の 292枚の木版画のように、実務書は図に依る。板に図を刻む費用は 053 以来の単価（字あたり）に入っていない。
  • 価値の模型の食い違い：054 の V_ext は T に読取装置の道の分（g_req の被覆）しか払わない。CH_heavy の費用を払いながら価値を読取装置の分しか数えないと、T＋C は過小に、S_TC は過大に評価される。逆に CH_reader の費用で数えると重い崩壊の前段の価値は 0 とみなすことになる。どちらの版が正しいかは、前段の知識が T0→T2 をどれだけ速めるか（新しい問い 153）で決まる。

新規性

Ord や XPT は文明再建の手引きの分量を扱わない。本回は、Project Gutenberg の 34冊の実務書の本文を実際に数え（模型に使ったのは29冊）、段ごとの字数の下限と上限を置いて手引きの字数を積み上げた。053 の 1e7〜1e8 と 024 の g_req は、全段の手引きと読取装置の部分という別のものの字数だったと示し、南半球の写しと束の順位が入れ替わる手引きの長さ（A_Ord 約390万字）を初めて示した。

この結果を受けて、誰が何を変えるべきか

金庫の運営者・手引きの企画者は、手引きを 約150万字の読取装置の部分（まず書き、金庫の束に入れる） と 約1,500万字の全段の部分 に分けて予算を組む。読取装置の部分だけなら、南半球への写し（約 $60万）より束そのものを先に作る方が費用あたりに効き、重い崩壊ではその差が大きい（P 0.91〜0.96）。本研究所は 053〜055 の T の字数を CH_heavy（約1,500万字）に改め、054 の価値の模型に前段の知識の価値を入れる（153）まで、S_TC を T＋C より上に置く順位は「全段を書く場合」の条件つきと記録する。
