批判的検討

  • 事例は T1 に近い社会への移転だった。佐賀藩は有田焼の職人、刀鍛冶、鋳工の頭梁、和算家、石見の鉄、そして歳入の4割を出す藩の財政を持っていた。重い崩壊の T0 の集団には当てはまらず、m_base U(1,4) は根拠のない幅である。逆に言えば、本だけの移転はこの好条件でも 3/7 しか意図した水準に届かず、人で移した例の約2.3倍の年数がかかった。
  • 事例の選び方：日本の幕末の例は「本しか手に入らなかった」ので本だけの例として残ったもので、人で移した例は成功した会社の記録である（失敗した移民の工場は記事になりにくい）。成功率の差 0.43 対 1.0 は選択で膨らんでいる恐れがある。標本も 7件と 4件で小さい。
  • 価値の物差し：054 の価値は「媒体の寿命と 1,000年の窓のうちに金庫を読めるか」だけで、前段の知識が早めるそのほかの利益（人の暮らし、早い回復による別の危険の回避、人口の増え方そのもの）は 0 に数えている。F が小さいのは手引きが役に立たないというより、この物差しでは人口の待ちが T2 到達を決めているためである。
  • **thr（閾値を下げる効果）**は本回の事例では確かめていない。閾値を 1/10 にすると F は 1.55 まで上がり、段を縮めるより効く。知識が「技術を維持するのに要る人数」を減らすかどうかは別の問い（新しい問い 155）。それでも 1/100 で 2.08（探索）で、5.0 には届かない。
  • この結果は 038 の「重い崩壊では T2 までの時間の 86% が人口待ち」と整合し、040 で T0 手引き PRIM が板の手引きの 1% 程度だったことの理由を、事例の年数を入れても変わらない形で確かめたものである。新しさは、前段を全部の段（d12 を含む）に広げ、年数を 0 にした上限でも結論が動かないことを示した点にある。
  • p_early の主の設定と、識字を失っても読めるという置き方は推測で、どちらも手引きに有利な側に置いた。

新規性

Ord や XPT、Dartnell の The Knowledge は「本があれば再建が速くなる」ことを前提か定性で扱う。本回は、本だけで技術を移した幕末の例（7件）と人で移した例（4件）の年数と成否を公開資料から表にし、それを段の年数の倍率として崩壊後の人口の模型に入れ、段を0年にしても前段の手引きは金庫の価値を 2% しか増やさないこと、効くのは知識の年数でなく人口の待ちであることを数値で示した。

この結果を受けて、誰が何を変えるべきか

手引きの企画者は、読取装置より前の段（約1,370万字）を板に刻む予算を、金庫の読み取りの価値を理由には組まない。読取装置の部分（約160万字）を先に書いて束に入れ、前段は既存の公開の実務書（Gutenberg など）の目録と要約にとどめる。本研究所は 056 の「S_TC を T＋C より上に置く順位は全段を書く場合の条件つき」を、「全段を書く理由は金庫の物差しの外にしかない」に改め、053〜056 の T の主の字数を CH_reader（約160万字）に戻す。重い崩壊で金庫の価値を動かすのは知識の年数ではなく人口の増え方と閾値（040 の GROW・CON、新しい問い 155）である。
