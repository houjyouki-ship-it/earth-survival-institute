批判的検討

  • OpenStax の費用は初版の、字数は第2版の値で、教科書と再建の手引きは書く中身が違う（手引きは試験した手順と図が要る）。手引きの方が字あたり高い可能性があり、そのとき S_TC・S_LD の CE はさらに上がり、T＋C の CE は少し上がる（C の割合が減るため）。
  • Wikipedia の時間は編集画面の中だけで、取りこぼし U(1,2) は【推測】。2倍以上なら WP の生産性はさらに下がる。
  • 編纂のアンカー（JAU、SME）は既存の文献の写しを含み、再建の手引きでは CC ライセンスの Wikipedia・OpenStax を要約する場合に当たる【推測】。V_mix の f_orig U(0.2,0.8) は根拠のない幅で、両端の版（V_orig・V_comp）で CE(S_TC) は 6.1〜24（A_Ord）動く。
  • S_LD の喪失（紙、空調なし、数百年）・受理・発見はすべて推測。NLA は手順書を選択的にしか集めないと書いており、受理されない恐れは現実にある。NZ の規定のページは開けていない。
  • 付け足した S_LD は T＋C の後の単独の追加で、S_TC と同時に置いたときの価値（重なり）は計算していない。

新規性

Ord や XPT は知識保存の費用を扱わない。053・054 は生産性を推測の 100倍の幅で置いていた。本回は公開の企画の記録（OpenStax の費用と GitHub の字数、Wikipedia の労働時間、Encyclopédie・Britannica・OED）から、原文の執筆と編纂の二つの帯を数値で示し、T の費用の幅を 1/10 に絞った。南半球の預け先として法定納本の制度（豪州の NLA の規定）を費用あたりの模型に入れたのも初めて。
