研究053：避難所と金庫の板の費用の比（open_problems 122）

問い

040 では、金庫の物差し（重み付きの ΔV）で避難所 REF(1e5) が板の手引き TAB の 0.27倍、REF(1e6) が 2.2倍（A_Ord・U3）だった。公開の建設費で両者の費用を置くと、費用あたりではどちらが効くか。避難所が板の手引きと並ぶ1人あたりの損益分岐の費用 c* はいくらか。重い崩壊と軽い崩壊で分けるとどうか。

批判的検討

  • 結論は桁で頑健で、仮定の細部には乗らない。最も避難所に有利な組み合わせでも CE は 0.014 で、並ぶにはさらに約70倍が要る。費用の幅（TAB で2桁、避難所で3桁）より差（5桁）の方が大きい。7つの仮説がすべて支持されたのは、事前登録の閾値が差に比べて緩かったため【推測】で、判定より桁の差を読むべきである。
  • アンカーは規模の経済を含まない。どれも数十〜数百人の施設で、10万〜100万人の町を自給させる費用ではない。A1（1962年の大量の避難所の試算）が規模の経済の代わりだが、6か月しか持たない。040 の REF は「生き残りの最大集団を N 以上に保つ」なので、本当は数年〜数十年の自給が要り、費用はアンカーより高い側に寄るはず【推測】。つまり避難所に有利な向きの偏り。
  • TAB の費用は執筆の仮定でほぼ決まる（99%）。執筆を既存の教科書・百科の編集と見れば安く、ゼロから書けば高い。ただし TAB を 10倍高くしても結論は変わらない。
  • 避難所の主な価値は金庫の物差しの外にある。本研究所の模型は「金庫が再出発をどれだけ速めるか」しか数えず、絶滅を防ぐ価値は入らない。だからこの結果は「避難所は無駄」ではなく、「避難所を金庫の価値（知識の保存と文明の回復）で正当化することはできない」という意味にとどまる。Beckstead 2015（040 で確認）の「避難所は多くの破局で人口・資源・技能にほとんど足さない」と同じ向き。
  • 040 の価値は 051・052 の改訂（A_Ord の主の値 0.00461）の前の値だが、TAB の重み付きの値は 040 の U3（0.00457）とほぼ同じで、比への影響は小さい【推測：REF は再計算していない】。
  • 重い崩壊を優先する方針との関係：避難所は価値の 83〜94% が重い崩壊から来る、ほぼ純粋な重い崩壊向けの対策だが、費用で約5桁負ける。重い崩壊の中でも、費用あたりで TAB に近いのは知識の対策（GROW、TAB 自身）だけだった。

結論

公開の建設費（1人あたり $2.5万〜4,400万）で置くと、10万〜100万人の避難所は $1,000億〜2兆ドル規模で、板の手引き（中央値 $460万、ほぼ執筆の費用）より金庫の物差しで費用あたり約5桁（XPT の重みでは7〜8桁）劣る。避難所が並ぶ1人あたりの費用は約 $10 で、1年分の食料の 1/300 しかない。最も避難所に有利な仮定を重ねても1/70 に届かない。重い崩壊に限っても同じ。人口の増え方を速める知識（GROW）は TAB と同じ桁で、どちらが勝つかは知識で r が上がるかしだい（費用あたりで勝つ確率 0.13〜0.35）。

この結果を受けて、誰が何を変えるべきか

  • 本研究所：避難所を知識保存・文明回復の対策の候補から外し、重い崩壊向けの対策の比較は知識の対策（TAB、GROW）と金庫の置き場所の間で行う。次は、Svalbard 種子庫の建設費（$880万）を拠点の費用の目安に使えるので、第2拠点と束の費用（103＋100）を同じ方法で比べる。
  • 避難所を提案する人：避難所の正当化は「文明の知識を保つ」ではなく絶滅を防ぐ価値で行う必要がある（金庫の全価値の 200〜2,000倍に当たる別の価値が要る）。金庫・手引きの予算を避難所に回すのは、金庫の価値の点では損である。

既存研究に対する新規性

Beckstead 2015 と Jebari 2014 は避難所を定性的に論じ、費用を知識の保存と比べていない。本研究は、同じ模型の価値（040）に公開の建設費のアンカー5つと MOM の媒体の価格を入れ、避難所と手引きの費用あたりの比（約 1e-5）と損益分岐の1人あたり費用（約 $10）を重い崩壊・軽い崩壊に分けて出した。確認した資料には、この比較は見当たらない。
