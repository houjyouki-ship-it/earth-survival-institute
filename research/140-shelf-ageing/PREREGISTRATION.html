課題（open_problems 322）

139 の模型で L_T3 を決めるのは保管の老化 a（無通電の予備が使用中の何倍の速さで劣化するか）だけだった。 部品の型ごと（電解コンデンサ、IC、SSD、HDD）に、公開の資料が示す主な劣化の機構が無通電でも進むか、進むなら温度・時間の則から a を置き、 139 の sim.py の L_T3 と 032 の NUC_G の重み付き ΔV を置き直す。

方法

  • 機構ごとに a = (保管条件での劣化の速さ)/(使用条件での速さ)。温度則（10 度で 2 倍など）が資料にあれば保管 25°C・使用 45°C（139 と同じ）で計算。 機構が通電・電圧・電流を要するなら a=0、無通電でも進む別の機構（例：はんだのウィスカー、湿気）があれば別に扱い、資料がなければ版として幅で置く。
  • 可逆な劣化（コンデンサの再化成で戻る漏れ電流など）は部品の死に数えない版と数える版を併記。
  • 139 の L_T3 関数を import して a の型ごとの値で再計算。032 は 139 と同じ写し方で再実行し、139 の結果の再現を assert。
