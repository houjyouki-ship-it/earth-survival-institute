課題（open_problems 321 (a)）

150 Tg（NUC_G）で電力を保った無傷の国が、半導体・部品の輸入なしに計算機の使える社会（T3）を何年保つか（L_T3）を、 公開の故障率の資料で既存の計算機の台数の減り方を模擬して出し、032 の NUC_G の状態の割合（T3 0.65 / T3_fragile 0.15 / 重い 0.19）を置き直す。

模型（sim.py）

  • 1 台の計算機は部品の型 j（記憶装置 HDD/SSD、電源・電解コンデンサ、その他）が 1 つずつ揃えば動く。共食い（部品の融通）ありとし、 動く台数 W(t) = min_j N0·u_j·S_j(t)。S_j は Weibull（尺度 η_j、形 β_j）。使わない予備は劣化しない版／使用と同じに劣化する版。
  • 初期の台数 N0 は国の人口 × 1 人あたりの台数（資料で置く、なければ版で 0.3〜1.0）。T3 の閾値 N_thr は 10³ / 10⁴ / 10⁵ 台（模型の版、資料なし）。
  • L_T3 = W(t) < N_thr となる最初の t。β と η は資料（AFR と年齢の曲線）で置く。β=1（摩耗なし）を版として必ず併記する。
  • 032 への写像：L_T3 ≥ 80 年 → T3 を保つ、20 ≤ L_T3 < 80 → T3_fragile、L_T3 < 20 → 重い崩壊（T2 以下）。電力で T3 を失う分（138 の 1−Q）は重い崩壊。 得た割合で 032 の sim.py の NUC_G の平均を置き換えて（mean_override）、A_Ord・A_XPT_S の重み付き ΔV を出す。
  • 再現：032 の sim を NUC_G の元の平均で回して results.json の重み付き ΔV（A_Ord 0.0178）と一致を assert。
