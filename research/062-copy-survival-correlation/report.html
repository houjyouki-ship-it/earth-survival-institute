批判的な検討

  • 版の数え上げは、有名で価値が高く集められた本だけで、現存部数がよく調べられた本ほど残りやすい（選択の偏り）【推測】。使われる本の唯一の例 Bay Psalm は τ 77年で、他の中央値の 1/7。座標の冊子は誰も価値を知らない本なので、図書館の書庫に入っても 77年の側に近いかもしれない。その場合の重い崩壊は 0.73 で、061 の 0.81 より低い。
  • 施設の出来事は「壊された図書館」の一覧から取ったので壊れ方は重い側に偏る。それでも、焼かれた地域の中でも施設ごと・1冊ごとに少しずつ残るので、写しは独立に近くなる。Warsaw の 70〜80% も「残りの 20〜30% の図書館」があることを意味する。
  • 061 の c が高く出る仕組みは物理的な壊れ方ではなく、「崩壊後の社会が古い図書館を探して読むか」が全写しに共通であることだった（E1 で含意の c 0.93）。この共通の要因の資料は本回ない。ここが最大の未知（→167）。
  • 地域の中で施設が独立という仮定は、核攻撃のように都市ごと丸ごと消える壊れ方には弱い。E2（地域ごとに焼く）でも結果はほぼ同じだったのは、焼かれた図書館でも1冊が 0.04 残る（s_b）と置いたため。都市ごと全部が 0 になる壊れ方の資料は本回ない（→168）。
  • 地域に分ける費用（外国の図書館への送付・交渉）は置いていない。K の効きが小さいので結論は変わらない。

新規性

写本や初期の印刷本の現存部数は書誌学でよく数えられているが、それを「写しを何部・何か所に置けば崩壊を越えて1部が読まれるか」の相関の推定に使い、物理的な壊れ方の相関と読む社会の共通の要因を分けたのは本研究所で初めて【推測：網羅的に調べたわけではない】。【独自仮説】長期の保存で写しどうしの相関を生むのは物理的な破壊より「読む人がいるか」で、部数や置き場所の分散は 10〜30部で頭打ちになり、その先は読まれやすさに投資すべき。

この結果を受けて、誰が何を変えるべきか

金庫の運営者は、座標の冊子を何百部も配るより、10〜30部を別々の図書館に預けたうえで、崩壊後に人が読みそうなもの（金庫の手引き自体、地図帳、百科事典、法定納本される普通の本の付録）に同じページを入れて読まれやすさを上げるべき。100部の費用あたりは 54 で南半球の写し（17.8）の約3倍のまま。本研究所は 061 の c~U(0.5,0.95) を「物理的な壊れ方では c≈0.1、読む社会が共通なら c≈0.9」と分けて記録し、重い崩壊での冊子の効きを 0.78〜0.87（使われる本の寿命なら 0.73）とする。次は、崩壊後の社会が古い蔵書を読む確率と時期（167）を、写本の再発見の記録から測る。
