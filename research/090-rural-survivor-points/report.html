研究090：全世界の GeoNames の群の点に農村の人口と市から郡部への移動を入れる（open_problems 218＋221）

注：TC/V0 は生存確率・復興確率ではない。提言は模型の中での順位（外部の検証はまだ）。

問い

075 の群の点（生き残りの居場所）は Natural Earth の人口つきの地名だけで、農村の人口がない。089 で崩壊の直後に人は市から郡部へ動く（日本 1940→1947、市 0.856・郡部 1.245）と分かった。全世界を GeoNames にそろえ、農村と移動を入れると重い崩壊の TC/V0 と置き方の順位はどう動くか。

方法

  • 087 の sim.py を「新しい点の集合」の前まで exec（075 の mesh35 と 084 の mesh35・pop@pt を差0で再現する assert を含む）。新しい関数 PT_s は NE の点と ppop で 075 の PT を完全に再現（assert）。新しい乱数なし（075 の UPT）。
  • 群の点：GeoNames cities1000 の全世界（PPLX を除く）154,895 点、A2 の 159 か国すべてに点あり。写しの場所は 074 の NE の点のまま。
  • 資料（本回取得、sources/ に保存し SHA256）：World Bank API の 2020 年の総人口 SP.POP.TOTL と農村人口の割合 SP.RUR.TOTL.ZS（https://api.worldbank.org/v2/country/all/indicator/SP.RUR.TOTL.ZS?format=json&date=2020&per_page=400 、158 か国が一致）。
  • 版：B_GN（人口に比例、農村なし）／R（主：国の重みを都市 u_c と農村 1−u_c に分け、農村の分を人口 1 万未満の点に等しく）／R_sqrt（pop^0.5）／R_all（全点に等しく）／M（R に都市 ×0.856・農村 ×1.245、089）／M2（倍率を2乗）／M_sqrt。

結果

【事実（出典：World Bank API、GeoNames）】GeoNames（PPLX 除く）の人口の合計は World Bank の総人口の 0.553 倍（国の中央値 0.669）。人口で重みづけた農村の割合は 0.433。

  • 確認的（資料の取得前に登録）：H102a 支持（0.553 < 0.8）、H102b 支持（0.433）。
  • 予測：H102c 支持（−0.0041）、H102d 支持（0.0066）、H102e 支持（−0.0026）、H102f 棄却（τ 0.689 で 0.7 にわずかに届かず、最良は mesh35 のまま）、H102g 棄却（+0.0465 < +0.0488）。

批判的検討

  • 写しの場所は NE の点（大きな町）のままなので、農村に生き残りを足すと届かない群が増えるのは作りの上で当然。農村に写しを置く置き方（GeoNames の点の上で網目を作り直す）はまだ比べていない（新規 223）。
  • 農村の分を人口 1 万未満の点に等しく配るのは代用。小さな点の密度は国の地名の登録の熱心さに左右される（GeoNames/WB の比が国で 0.67 の中央値でばらつく）。格子の人口（GHSL など）との比較は残す（195・218 の残り）。
  • 089 の倍率は日本の1局面（市町村の境の変化と戻りを含む）を全世界に当てた。M2 でも結果は同じなので、倍率の不確かさは結論を動かさない。
  • 【独自仮説】点の模型の欠けは重い崩壊の TC/V0 を約 0.01 押し下げるが、置き方の判断（網目＞人口の大きい点＞地域ごと）は変えない。
