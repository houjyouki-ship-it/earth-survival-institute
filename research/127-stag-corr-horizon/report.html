研究127：停滞と段の喪失の相関、地平 H の感度（open_problems 298・299）

注：F_heavy・V は生存確率や復興確率ではない。模型の中の相対的な価値の比である。提言は模型の中での順位（外部の検証はまだ）。

何をしたか

126 の sim.py を前半まで exec し（126 の assert 4 つが通る）、125 と同じ乱数で停滞を引き直した。 停滞の確率を「基準で段を失った標本（st 4〜6）」とそれ以外で分ける 5 版（V0 なし、C0 独立 p=0.6、Ccond 段の喪失だけ p=0.6、Cmid 0.8／他で全体 0.6、Cmass 全体 0.6 を保つ完全相関で段の喪失の中 0.864、C1 段の喪失の中 1.0）を、地平 H=1000・1500・2000 年で計算した。 H=1000 の V0・C0 は 126 の V0・V2b の table と差 0（assert）。

  • H139b（確認的）：H2000 の上げ幅 0.281 は H1000 の 0.359 の半分未満ではない → 棄却。H の切り捨ては上げ幅の約 2 割だけ。
  • H139c（確認的）：順位不変 → 支持。

批判・限界

  • 本当の問いは「125 の p=0.6 は周辺の確率か、段を失った社会の中の確率か」。125 の事例は人口が半分以上減った崩壊（L≥0.5）で、技術の段を失ったかは記録していない。条件つきと読めば 126 の 1.888 がそのまま正しく、周辺と読めば 2.18 になる。今回はこの幅を出しただけで、どちらかは決めていない【推測】。
  • 型（CASC/BIO）に寄せる版は、F_heavy が U3（型のない未知の人為リスク）だけで決まるので作っていない。
  • H=∞ は作っていない（life が先に切るので H2000 との差は小さいと見込むが確かめていない）。
  • 停滞の長さは 3 値のまま、停滞の間の κ は変えていない（300）。

誰が何を変えるべきか（模型の中での順位、外部の検証はまだ）

模型の維持者は、重い崩壊の F_heavy を 1 つの値でなく「p|lost の読み方の幅」で出す：H1000 で 1.89〜2.18、H2000 で 1.75〜1.97、量は −9〜−15 %。H を延ばす感度は小さいので優先を下げ、代わりに寿命 life の分布（中央 521 年）の出典を確かめる。読取装置の推し D2rz は変えなくてよい。
