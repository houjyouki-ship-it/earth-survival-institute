1. 背景と目的

  • 【事実（Ord 2020 第1章 https://80000hours.org/wp-content/uploads/2020/03/The-Precipice-Introduction-Chapter-1.pdf ）】今世紀の存続リスクは約1/6（001と同じアンカー）。
  • 【事実（Karger et al. 2023, XPT 報告書 Table 1・3, https://forecastingresearch.org/pdf/existential-risk-persuasion-tournament.pdf ）】2100年までの人類絶滅（人口5,000人未満）確率の中央値は超予測者1%、専門家6%。大災害（5年以内に10%以上が死亡）は9.05%と20%。
  • 研究001の限界2点を扱う：(a) h0（危険強度）と τ（危険の時代の長さ）を独立とした仮定、(b) 新技術でハザードが一時的に上がる「増加型」を含まないこと。

2. モデル

h(t) = h0·exp(−t/τ) + h_nat + h_pulse(t)、S(T) = E[exp(−∫₀ᵀ h)]。 - h0 中央値 = 1−(5/6)^(1/100) = 0.001822/年、τ 中央値 = 200年、h_nat = 1/87,000/年、σ = 1.0（001と同一。001と同じ乱数列なので ρ=0 は001の baseline と全桁一致：S(100)=0.82607…）。 - (a) 相関：(log h0, log τ) を相関 ρ の2変量正規。全ρで同じ乱数（共通乱数法）を使い、ρ間の差にMC雑音が乗りにくくした。実現した相関は設定値±0.002（rho_scan.*.empirical_corr_log）。 - (b) パルス：面積 A·w を共通にした3形状 — 矩形 [t0, t0+w]、三角形（同じ台、ピーク2A）、ガウス（中心 t0+w/2、sd=w/√12、t<0 を切って面積を再正規化）。A ∈ {0.1, 0.5, 1, 2}×h0、w ∈ {30, 100, 300}年、t0 ∈ {0, 50, 200}年。【推測】パルスは「現行推定に含まれない追加リスク」（例：未知の新技術）という位置付け。 - (c) 反例探索用の脆弱化（自己励起）モデル【独自仮説の道具】：人為ハザード（危険の時代の項＋パルス）は、絶滅ハザードの c 倍の率で非致死的な大災害を起こし、大災害1回ごとにそれ以後の危険の時代の項が (1+δ) 倍になる。c は XPT の「大災害／絶滅」中央値比をアンカーにした：専門家 20/6 ≈ 3.33、超予測者 9.05/1 ≈ 9.05【計算（XPT Table 1 の値から）】。δ ∈ {0.5, 1.0} は根拠のない仮定。時間刻みは 1年（〜1000年）、10年（〜2万年）、100年（〜10万年）。δ=0 のとき解析式と 1e-15 の精度で一致（damage_model.validation_*）。

4. 独自仮説と検証（判定基準は計算前に置いた）

H4【独自仮説】正のρは独立時より S(1万年) を下げる（log(h0τ) の分散 σ²(2+2ρ) が広がるため）。 基準：Ordアンカーで S(1万年) が ρ について単調減少し、端点差 > 3×SE。 - Ordアンカー・σ∈{0.5,1,1.5,2}・XPT両アンカーのすべてで単調減少（例 σ=1：0.5945→0.5242、差0.070 ≫ SE 0.0007）。 - 反例探索：h0 中央値を k 倍すると、k ≈ 2.07（σ=1）で符号が反転し、それ以上では正のρの方が S が高い（k=10：ρ=+0.8 で 0.184、−0.8 で 0.060; h0_scale_scan_S1e4）。反転点は σ=0.5 で k=2.36、σ=2 で k=1.92。危険の時代の項だけで見た中央値世界の生存確率は反転点で 0.42〜0.50（H4_sign_flip_by_sigma）。 - 解釈【推測（数学的直観）】：中央値を固定して分散を広げると E[exp(−X)] は 1/2 に近づく。中央値世界が生存側（>0.5 付近）にあるなら分散拡大は損、破局側にあるなら得になる。 - 判定：条件付き支持。「中央値世界の危険期生存確率がおよそ0.5より高い」ときだけ成り立つ。Ord・XPT専門家・XPT超予測者のどのアンカーもこの領域（危険期の中央値生存 0.69/0.85/0.97【計算】）なので文献の範囲内では成立するが、h0 が Ord の約2倍を超える悲観的な世界観では逆転する。

H5【独自仮説】負のρは「強いが短い」世界を増やして S を上げる。 基準：(i) ρ<0 で S(1万年) が独立時より高い。(ii) 機構が「強いが短い」世界の生存によるなら、その世界群の生存質量シェアは出現頻度より明らかに大きいはず。追加の基準 (iii)：長期の ρ効果が log(h0τ) の分散だけで決まるなら、同じ分散を持つ独立モデル（各 σ'=σ√(1+ρ)）と S(1万年) が一致するはず。 - (i) 成立：0.5945（ρ=−0.8）> 0.5448（ρ=0）。 - (ii) 不成立：ρ=−0.8 で「h0>中央値かつτ<中央値」の世界は頻度 39.7%、1万年生存質量シェア 40.1%（ρ=0 では 24.9% と 26.6%）。強いが短い世界は平均並みにしか生き残らない。 - (iii) 成立：S(1万年) は全ρで等分散独立モデルと差 ≤0.00011（SE以下）。ただし短期は一致しない：S(100) は ρ=−0.8 で 0.848 vs 0.857、S(1千年) は 0.682 vs 0.666。 - 判定：現象は支持、機構は棄却。負のρが S を上げるのは「強いが短い世界が生き残る」からではなく、累積危険 h0τ の分散が縮むから。この効果も H4 と同じ反転条件に従う（k>2.07 では負のρが S を下げる）。

H6【独自仮説】パルスは直近100年の S を大きく削るが、長期 S への影響はパルス面積 A·w にほぼ依存し、形状には鈍感。 基準（事前）：同じ面積なら形状・時期・幅の違いによる S(1万年) の差 < 0.005。 - 純ハザードモデル：パルスが評価時点までに終われば、相対減少は exp(−A·w) で厳密に決まる（数値でも全桁一致）。ただしこれは加法的ハザードの恒等式で、検証というより確認である。「直近100年を大きく削る」は絶対値ではそう見える（−13.8pt vs −9.1pt）が、相対では同じ（16.7%）。例外は評価時点で未完のパルス（w=300 で形状差3〜4pt、w=2万年で打切り）。 - 脆弱化モデル（反例探索）：同じ面積でも S(1万年) の相対減少は 17.6%〜32.0%（c=3.33,δ=1）、18.7%〜58.4%（c=9.05）。早い・狭いパルスほど害が大きい（危険の時代の項がまだ大きいうちに乗数が掛かるため）。一方、同じ台・同じ時期の形状差（矩形/三角/ガウス）は ≤0.4pt（相対）で、基準内。 - 判定：純ハザードモデルでは支持（ただし自明）、脆弱化モデルでは「面積のみ」の部分を棄却。「形状に鈍感」の部分はどちらのモデルでも残るが、「時期と集中度」は脆弱化があれば同面積パルス間で1.8倍（c=3.33）〜3.1倍（c=9.05）の差を生む。新リスクの評価には面積（累積確率）だけでなく、危険の時代のどの段階で起きるかが必要になる。

5. 批判的検証（限界）

  • 脆弱化モデルの δ には文献アンカーがない。c は XPT の「中央値の比」で、個人ごとの比でも条件付き確率でもない。【推測】δ=1（大災害1回でその後の人為リスクが2倍）は強い仮定で、脆弱化の結論（S(1万年) 0.544→0.395）は定性的な目安にとどまる。さらに大災害による「回復不能な崩壊」そのものは数えていない。
  • ρ の符号を決める実証データはない。【推測】「危険な技術を早く制御できる社会ほど危険の時代も短い」（正のρ）とも、「強いリスクは早く対処される」（負のρ）とも言えるので、本研究は符号ではなく感度を示した。
  • XPT の年率化（約78年で一様）と、Ord（存続破局）と XPT（絶滅）の定義差により、アンカー間の比較は大まかなものにとどまる。
  • 指数減衰形・h_nat を上限値で固定・σ=1 は001から引き継いだ仮定のまま。
  • パルス×ρ の結果（3.3）は事前登録していない探索的な観察。

6. 結論

  1. 【計算】h0–τ の相関は Ord アンカーで S(1万年) を 0.524（ρ=+0.8）〜0.594（ρ=−0.8）の範囲で動かす（独立 0.545）。001の不確実性込み推定に対して ±5pt 程度の幅。
  2. 【独自仮説・条件付き支持】「正相関は長期生存を下げる」は、中央値世界の危険期生存がおよそ0.5より高いときだけ成り立つ。Ord の2倍を超える悲観的な h0 では符号が逆転する。
  3. 【独自仮説・機構棄却】負相関の利得は「強いが短い世界」の生存ではなく、累積危険の分散縮小から来る。長期 S は log(h0τ) の分散だけで決まる（短期は決まらない）。
  4. 【独自仮説・部分棄却】一時的な新リスクの長期的な害は、純ハザードモデルでは面積だけで決まるが、非致死的大災害が以後のリスクを上げる世界では「早く・集中して」起きるほど重くなり、相対損失は純ハザード（16.7%）の最大1.9倍（c=3.33,δ=1）〜3.5倍（c=9.05,δ=1）に達する。→ 脆弱化パラメータ δ の推定が新しい最重要の未解決量になった【推測】。
